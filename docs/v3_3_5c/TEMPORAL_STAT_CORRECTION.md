# V3.3.5b temporal 통계 정정

모델 생성은 다시 실행하지 않았다. 기존 CONFIRM 60개 프롬프트의 1,740개 저장 행을
그대로 읽고, 20,000회 prompt-cluster bootstrap만 고쳤다.

## 정정 방법

seed 7로 단 하나의 `IDX[20000,60]`를 만든 뒤 모든 B2와 네 사전 대비에 같은
행을 재사용했다. 각 replicate에서 16개 대비 통계 전체를 계산하고 그 절댓값의
family maximum으로 max-T 임계값을 얻었다. 정정 임계값은 **3.017031**이며 기존
3.024447과 가깝지만, 이제 반복측정 covariance를 보존한다.

유의하고 실질적으로 나쁘므로 TD1이 아니다. 어떤 같은 분산 schedule/B2 조합도
P0와 G1을 모두 이기지 못한다. P0 대비 큰 예산 구간들이 `-SESOI` 아래이므로

이 판정은 역사적 GLOBAL 차이의 원인을 accumulation 하나로 확정하지 않는다.
