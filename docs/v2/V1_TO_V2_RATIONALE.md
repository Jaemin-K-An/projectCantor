# V1 → V2: 왜 Cantor 고유 효과가 사라졌는가

이 문서는 V2 작업 이전에 V1 저장소 전체를 읽고 작성한 요약이자, V2의 출발점이다.
**V1의 negative result는 유효하며, 본 문서는 그것을 뒤집지 않는다.**

---

## 1. V1이 실제로 무엇을 했는가

V1(`docs/FINAL_REPORT_KO.md`)은 1차원 게이트 동역학계

    ḣ = −α(h − ½) + g_n(h)·δ(t),   S = [1/3, 2/3]

에서 칸토어 게이트의 강건성을 검증했다. 319,703회 궤적 적분과 11,794개
assertion으로 다음을 확립했다.

| 결과 | 내용 |
|---|---|
| 재현 | 29.80 / 98.17 / 97.43 % (원본 29.8 / 98.2 / 97.4) |
| 감사 | `h₀ = 0.15 ∈ (1/9, 2/9)` — 게이트가 30초 중 0.17 %만 열림 |
| 정리 1 | `S° ⊂ F_n`이므로 `S°`의 전방불변성은 **δ와 무관한 항등식** |
| RQ1 | `R_safe`는 `n`에 대해 비단조 (n=1 최대, n≈7 최소) |
| RQ2 | 측도정합 대조군 대비 백분위 41–52 — **프랙탈 이점 없음** |
| RQ4 | Neural ODE에서도 게이트 효과는 진폭 외삽에만, Cantor 특이성 없음 |

## 2. V1 게이트가 버린 정보

V1이 실제로 컨트롤러에 넘긴 양은

    g_n(x) = C'_n(x) / (3/2)ⁿ = 1_{K_n}(x) ∈ {0, 1}

정규화 상수 `(3/2)ⁿ`으로 나누는 **그 한 줄**에서 다음이 전부 소실된다.

| 소실된 정보 | V1에서의 상태 |
|---|---|
| derivative magnitude `(3/2)^k` | 1로 정규화되어 제거 |
| removal level `k` | 게이트는 "제거되었는가"만 알고 "몇 번째 레벨에서"는 모름 |
| gap width `3^{-k}` | 모든 gap이 동일하게 취급됨 |
| level별 gap 개수 `2^{k-1}` | 사용되지 않음 |
| scale별 mass redistribution | 완전히 소실 |
| hierarchical self-similarity | 위치 정보로만 남고 강도 정보 없음 |

`1_{K_n}`은 **집합 멤버십**이다. 칸토어 함수의 본질인
"측도가 줄어드는 만큼 미분값이 커져 질량이 보존된다"는 성질은
정규화 시점에 사라진다.

V1 §11의 ablation(G2 random, G5 shuffled)이 통과측도를 정확히 맞춘 것은
**옳은 실험이었지만**, 그 실험이 검증한 것은

> "이진 마스크의 공간 배치가 중요한가?"

이지

> "칸토어의 척도별 질량 재분배가 중요한가?"

가 아니다. V1은 후자를 애초에 컨트롤러에 넣지 않았다.

## 3. V1 정리 1이 이미 말해주는 것

V1 정리 1의 증명은 `g(S°) = 0` **하나만** 사용한다. 즉 V1의 게이트 설계에서는
정의상 "안전집합을 덮는가"가 전부이고, 나머지 구조는 정리에 등장할 여지가 없다.
V1이 프랙탈 이점을 찾지 못한 것은 실험의 실패가 아니라 **컨트롤러 설계의
논리적 귀결**이다.

따라서 V2의 질문은 다음과 같이 좁혀진다.

> **칸토어를 이진 마스크로 축약하지 않고, level-dependent
> measure-concentration 구조를 실제 control field의 크기에 반영하면
> 결과가 달라지는가?**

## 4. V2가 바꾸는 것 — 딱 한 가지

V1: 게이트는 `K_n` **위에서** 작동하고 gap에서는 아무 일도 하지 않는다.
V2: 컨트롤러는 **gap 안에서** 작동하고 `K_n` 위에서는 0이다.

즉 V2는 V1의 지지집합을 **뒤집는다**. 그리고 각 gap에 실리는 힘의 크기를
그 gap의 level에 따라 다르게 준다 — 이것이 V1이 정규화로 버린 바로 그 정보다.

세부는 [`MATHEMATICAL_THEORY.md`](MATHEMATICAL_THEORY.md).

## 5. V1에서 물려받는 자산

* `src/CantorCore.jl` — 정확한 유리수 구간 표현, `cantor_gap_widths`,
  `in_cantor_set_stable`, 끝점 조건수 진단
* `src/Perturbations.jl` — 진폭 정합된 섭동 라이브러리 (V2에서 log-uniform 확장)
* `src/Metrics.jl` — 지표 정의, 사다리꼴 적분 규약
* `src/Dynamics.jl` — **고정스텝 RK4를 주 적분기로** 쓰는 방법론적 결론
  (불연속/스위칭 우변에서 적응형 솔버가 슬라이딩 모드로 실패한다는 V1의 발견)
* `src/Utils.jl` — provenance 사이드카, append-only 원자료 정책

V2 컨트롤러는 `Φ'(0)=Φ'(1)=0`인 smoothstep을 쓰므로 **C¹ 연속**이다.
V1의 하드 게이트와 달리 스위칭면이 없고, 따라서 V1이 겪은 슬라이딩 모드
문제가 구조적으로 발생하지 않는다. 그래도 주 적분기는 V1과 동일하게 유지한다.

## 6. V1을 수정하지 않는다

`original/`, 기존 `results/raw/*`, `figures/*`, V1 `docs/*`는 그대로 둔다.
정정이 필요하면 [`V1_ERRATA.md`](V1_ERRATA.md)에 추가한다.
V2 산출물은 `configs/v2/`, `scripts/v2/`, `results/v2/`, `figures/v2/`,
`docs/v2/`, `llm/`로 namespace를 분리한다.
