# 정리 CR — Cross-Leaf Robustness

## 설정

대칭 이진 재귀 분할 `[ρ | 1−2ρ | ρ]`, 깊이 `n`.
`L_n°` = terminal leaf **내부**(open)의 합집합.

```
d_leaf(r) = inf{ |δ| : r+δ 가 다른 terminal leaf에 속함 }
M_n(ρ)    = inf_{r ∈ L_n°} d_leaf(r)
```

## 정리 CR

```
M_n(ρ) = ρ^{n−1}(1 − 2ρ) = G_n(ρ)
```

**증명.** 한 terminal leaf에서 다른 leaf로 가려면 최소 하나의 분리 guard를
가로질러야 한다. level-k guard의 폭은 `ρ^{k−1}(1−2ρ)`이고 `ρ < 1/2`에서
`k`에 대해 감소하므로, 깊이 `n`에서 가장 좁은 분리 guard는 level-n guard이며
폭은 `ρ^{n−1}(1−2ρ)`다. leaf 내부는 **열린 집합**이므로 그 guard의 가장자리에
임의로 가까운 점을 취할 수 있고, 따라서 거리는 guard 폭에 임의로 가까워지지만
**결코 도달하지 않는다.** ∎

> **infimum이지 minimum이 아니다.** 수치 검증에서 실측 하한은
> `M_n`을 항상 **위에서** 접근한다 (비 1.0000–1.0013, 격자 해상도 한계).

## 따름정리 CR.1 — 깊이 3

```
M_3(ρ)  = ρ²(1−2ρ)
M_3′(ρ) = 2ρ(1−2ρ) + ρ²(−2) = 2ρ − 6ρ² = 2ρ(1−3ρ)
```

`(0,1/2)`에서 `M_3′ > 0` (ρ<1/3), `= 0` (ρ=1/3), `< 0` (ρ>1/3).

> **`ρ = 1/3`이 깊이 3에서 worst-case 직접 terminal-policy 전환 여유를
> 최대화하는 유일한 축약비이며, `M_3(1/3) = 1/27`.**

## 일반 깊이 — 1/3은 n=3에서만 특별하다

`M_n′(ρ) = ρ^{n−2}[(n−1) − 2nρ]` ⟹ **`ρ_max(n) = (n−1)/(2n)`**

| n | 2 | **3** | 4 | 5 |
|---|---|---|---|---|
| `ρ_max` | 1/4 | **1/3** | 3/8 | 2/5 |

**다른 깊이에서 1/3은 최적이 아니다.** 일반화하지 않는다.
