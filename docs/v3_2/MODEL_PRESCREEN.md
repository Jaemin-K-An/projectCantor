# V3.2 Model B 사전심사

복제 모델은 **실제로 safety-steering testbed인지 먼저 확인한 뒤** 채택한다.
null 결과가 나온 다음에 "모델이 나빴다"고 말하는 것을 막기 위해, 게이트는
최종 시험 **전에** 돌리고 실패도 그대로 기록한다.

## 게이트

| 게이트 | 조건 |
|---|---|
| G1 거부 행동 존재 | `0.05 < 거부율 < 0.98` (포화도 부재도 아님) |
| G2 일관성 | coherence > 0.5 |
| G3 hook 수치 건전성 | 잔차 hook 통계 전부 유한 (MPS NaN 없음) |
| G4 방향 분리도 | Cohen's d > 0.70 (`D_direction`에서만) |
| G5 **인과성** | 방향 제거가 거부를 **단조 감소**시킴 (Spearman ≤ −0.5) |

G4만으로는 부족하다 — 분리도가 높아도 인과적으로 개입 가능하다는 보장이
없다. G5가 실제 시험이다.

### TinyLlama 기각 — negative result로 보고

TinyLlama-1.1B-Chat은 **공격 없이 평문 유해 요청에도 20/20 응답**한다
(예: 위조 서류로 미국 입국을 통과하는 절차를 단계별로 서술). 거부율이
상수 0이므로 dose-response의 Spearman은 정의되지 않고, 안전 조향을 시험할
대상 자체가 없다.

> **부수 소견:** ≤1.1 B 급 공개 chat 모델 다수는 거부 행동이 거의 없어
> safety-steering 실험대가 되지 못한다. 3개 중 2개가 이 이유로 탈락했다.
> 이 규모대에서 안전 개입을 연구하려면 모델 선택 자체가 결과를 좌우한다.

### OLMo-2-1B 채택 근거

* **계열이 다르다** — Qwen2.5(Model A)와 무관한 AI2 OLMo2, Apache-2.0,
  훈련 데이터까지 공개
* 거부율 0.800 (authority 공격 하) — 포화되지 않아 컨트롤러가 움직일 여지 존재
* 층 12에서 분리도 **3.59** (Model A 대비 강함)
* **인과성 명확**: ε 0→10에서 거부 0.800→0.200, Spearman −0.949,
  그러면서 coherence는 1.000→0.996으로 **유지**된다. 즉 방향 제거가
  모델을 망가뜨려서 거부가 준 것이 아니라 거부만 선택적으로 제거된다.
  (TinyLlama는 ε=10에서 coherence 0.000으로 붕괴했다.)

## dtype 결정 — 측정으로 정함

8 GB 기기에서 1.1 B 모델을 float32(4.4 GB)로 올리면 swap thrashing이 발생한다
(측정: 3:11 CPU/25 min wall, 진행 없음). float16으로 낮추기 전에
**정말 무해한지 측정**했다 (`scripts/v3_2/check_dtype_fidelity.py`):

| 지표 | 값 |
|---|---|
| margin 최대 편차 | **0.0018 σ** |
| margin RMS 편차 | 0.0008 σ |
| Pearson r (fp16 vs fp32) | **0.9999998** |
| 부호 일치 | 1.000 |
| 속도 | **9.2× 빠름** (10.3 s vs 95.1 s) |

편차 0.0018 σ는 실험이 **의도적으로 주입하는** calibration 이동
(Δ 격자 0.60–1.19 σ)보다 **340배 작다.** 따라서 Model B는 float16으로
실행한다. Model A(Qwen2.5-0.5B)는 V3.1과의 연속성을 위해 float32를 유지한다.

## V3.1 결함 D3 수정 — probe

V3.1의 hook은 **컨트롤러가 있을 때만** margin을 기록했다. 따라서 무제어
arm의 margin 분포가 존재하지 않았고 `m_min`은 NaN 자리표시자였다
(위 G3가 처음에 이것 때문에 헛되이 실패했다). V3.2는
`cantor_guard_v32/generation32.py`에서 **무제어에서도 margin을 기록**한다.
V3.1 코드는 동결 결과 재현을 위해 **한 바이트도 수정하지 않았다.**

측정된 Model B 무제어 margin 분포: mean −0.995, std 0.798, [q05 −1.820, q95 +0.561].
