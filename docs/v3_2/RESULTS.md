**결론 뒤집힘 2건:**
1. `T1_true_constant` **유의 → 비유의.** V3.1의 부차 주장
   *"다척도가 진짜 상수보다 낫다"*는 goal 군집을 반영하면 0을 포함한다.
2. `T2_global_smooth` **동등 → 비동등** (CI가 −0.03을 근소하게 벗어남).

**뒤집히지 않은 것 — 그리고 이것이 주요 결론이다:**
폭·에너지 정합 대조군에 대한 동등성은 **오히려 강화된다.** 정합 대조군의
군집 CI는 모두 naive보다 좁거나 같고(0.70–1.01×), 전부 SESOI ±0.03 안에
완전히 들어간다. 이 대조군들은 goal별로 칸토어와 **함께 움직이므로**
(어려운 goal에서 함께 실패) 군집 재표집이 공통 변동을 상쇄한다.

거부만 선택적으로 제거된다. (TinyLlama는 ε=10에서 coherence 0.000 붕괴.)

(r = 0.9999998), 이는 실험이 주입하는 calibration 이동(1.63–2.18 σ)보다

**ε는 모델마다 다르게 정해진다.** `D_dev` 측정에서 Model A는 ε=2에서
안전도 0.203, Model B는 ε=7에서 0.168 — 두 모델을 **같은 난이도**로 공격해야
컨트롤러 효과를 모델 간 비교할 수 있다. OLMo-2가 훨씬 강건하다
(baseline 거부율 0.94 vs Qwen 약 0.3).

**ε ≥ 5는 시험 격자에서 제외했다** (`D_test` 접근 전 결정). Model A의
`D_dev` 실측에서 ε=3에 이미 0.053, ε=5에 0.004로 **전 컨트롤러가 바닥에
붙어 판별력이 없고**, 그 영역에서는 `q_cap`이 거의 모든 토큰에 걸려
`C_rms(η)`에 꺾임이 생겨 실현 예산 정합이 불가능해진다. 판별하지 못하는
셀을 위해 공정성 제약을 희생하지 않는다.

**이득 해법:** `C_rms`는 `η`에 단조 비감소이므로 **이분법**으로 푼다.
secant는 꺾인 함수에서 진동해 `T3`/`T4`/`T5`가 −13.5 %…+13.4 %로 실패했고,
이분법으로 바꾸자 **13/13이 ±1.8 % 안에** 들어왔다
(`T3_wide_central`은 secant가 η=249로 발산했으나 실제 해는 η=0.845).

### 6.3 V3.1의 부차 주장은 다시, 더 강하게 부정된다

V3.1은 *"다척도가 진짜 상수보다 낫다"*(+0.018)고 주장했다. V3.2에서:

* 군집 보정 후 V3.1 데이터에서 이미 유의성 상실 (§1)
* Model A `LEX32`: +0.0021 [−0.0107, +0.0213] — **유의하지 않음**
* Model A `EXT`: **−0.0091 [−0.0190, −0.0014]** — **진짜 상수가 칸토어를 유의하게 이긴다**
* `EXT`에서 `T2_global_smooth`도 칸토어를 이긴다 (−0.0203), `T8_minimax`도 (−0.0075)

즉 **외부 채점기 기준으로는 다척도 개입이 오히려 불리하다.**

### 6.4 채점기 불일치 — 숨기지 않는다

| | `LEX32` | `EXT` |
|---|---|---|
| 최고 family | `T3_wide_central` 0.1037 | `T2_global_smooth` 0.2454 |
| `T7_cantor` 순위 | 2위 (0.1006) | **6위** (0.2250) |
| 일치도 | raw 0.855, κ 0.479 | |

두 채점기는 **Q_B·Q_C에서 방향이 반대**다. 그럼에도 **Q_D(칸토어 고유 질문)
에서는 둘 다 동등**을 준다 — 판정이 채점기에 의존하지 않는 것은
**결정적 비교뿐**이다. 이것이 두 채점기를 모두 보고하는 이유다.

### 6.5 실현 예산의 일반화 — 그리고 그 한계

`D_budget`에서 13/13이 ±1.8 %로 맞았으나, `D_test`에서 세 계열이 이탈했다:

|---|---|---|
| `T2_global_smooth` | 0.01671 | **−16 %** |
| `T3_wide_central` | 0.01450 | **−27 %** |

**10개 goal에서 맞춘 이득이 50개 goal로 완전히 전이되지는 않는다.**
이것은 결과이지 고칠 대상이 아니다(사전계획 §7: 재조정 금지).


**판정 불변.** 결정적 비교 셋은 원래부터 `D_test`에서도 정합되어 있었다
(0.0197–0.0202 vs 칸토어 0.0199).

### 6.6 Model A 요약

> 실현 개입 예산을 맞추고, goal을 추론 단위로 삼고, 독립 채점기를 병행하고,
> 50개 held-out goal에서 측정했을 때 — **칸토어의 재귀적 배치는 폭·에너지
> 정합 대조군과 실질적으로 구별되지 않는다.** 배치를 뒤섞거나(shuffled),
> 중앙에 몰거나(center-anchored), 균등 간격으로 놓아도(periodic) 안전도는
> SESOI 안에서 같다.

### 7.1 판정 — 사전 규칙이 강등했다

```
safe_lex32 : E_INCONCLUSIVE   (정합 CI가 0을 배제하지도, SESOI 안에 다 들지도 않음)
safe_ext   : C_PRACTICALLY_EQUIVALENT
FINAL      : E_INCONCLUSIVE_SCORER_DEPENDENT
```

`LEX32`에서 `T5_shuffled` 비교의 CI가 −0.03을 넘어가고(−0.0404) **검정력이
0.65로 부족**하다. 사전등록 규칙에 따라 **채점기 의존 판정은 강등**된다.

### 7.2 Model B가 Model A를 반박하는가 — **아니다**

* **어느 대조군도 칸토어를 유의하게 이기지 않았고, 칸토어도 어느 대조군을
  이기지 않았다.** 5개 비교 전부 CI가 0을 포함한다.
* 점추정은 모두 −0.013 ~ +0.004로 **SESOI의 절반 이하**다.
* `EXT`(검정력 0.88–0.98)에서는 **세 정합 비교 모두 동등**이다.
* `LEX32`가 판정 불가인 것은 **효과가 커서가 아니라 검정력이 낮아서**다
  (공격 1종, 인스턴스 8개, 검정력 0.55–0.72).

즉 Model B는 "칸토어가 다르다"가 아니라 **"이 예산으로는 말할 수 없다"**를
말한다. 이것은 사전에 등록된 규칙이 정직하게 작동한 결과다.

### 7.4 외부 채점기에서는 무개입이 최고였다

`EXT` 기준 family 평균: `T0_none` **0.7771**이 모든 컨트롤러보다 높다
(칸토어 0.7504). Q_A가 −0.0267로 음수인 이유다. 다만 CI가 0을 포함하고
검정력이 0.43이라 유의하지 않다.

이는 §2에 기록한 `EXT`의 편향(사실 정정을 거부로 분류)과 무관하지 않을 수
있다 — OLMo-2는 거짓 전제를 **정정**하는 응답을 자주 내놓고, 개입이 그
정정을 방해하면 `EXT` 점수가 떨어진다.
