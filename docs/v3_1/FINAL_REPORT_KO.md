# 안전 판정 경계 불확실성 하의 언어모델 잔차 다중척도 제어: 칸토어 구조 기반 연구의 종결

*Safety-Boundary Uncertainty and Multiscale Residual Control in Language
Models: Closing a Cantor-Based Study*

---

## 1. 초록

V1은 칸토어 도함수를 정규화한 **이진 게이트**에서, V2는 척도 정보를 복원한
**척도보상 장벽**에서, V3는 **경계 불확실성**을 도입한 합성 모형에서
각각 칸토어 고유의 이점을 찾지 못했다. 그러나 V2의 LLM 실험은 주 종점이
구조적으로 퇴화했고, V3의 두 헤드라인은 **코드 결함 위에 서 있었다.**

V3.1은 남은 confound를 제거하고 결론을 확정한다.

**수정.**
`L1_constant`가 실제로는 광폭 smoothstep 장벽(range 1.500)이었음을 밝히고
**진짜 상수 컨트롤러**(`∂u/∂r = 0`, 기계정밀도)를 구현했다.
`C0_fixed`가 V2의 calibration이 아님을 밝혔다.
정리 S의 퍼텐셜 항등식에 가법 상수를 복원하고, **전역 Corollary S.1이
거짓임**을 반례로 보인 뒤 증명된 **국소판 S.1′**로 대체했다.
L9를 동결하고, mechanism·synthetic을 재실행했다.

**새 정리.**
> **정리 T.** `‖u′_k‖_∞ = 6·e_k/w_k² = 12·E₀·(9/2)^k`, 따라서
> `S_u(Δ) ≤ ‖u′‖_∞·|Δ|`이며 진짜 상수는 `‖u′‖ = 0`이므로 `S ≡ 0`.

측정/예측 비 **1.000000** (n = 2…8). 같은 예산에서 다척도 장벽은
광폭 장벽보다 **738배**, 상수보다 **무한히** 경계 오차에 민감하다.

**합성 재실행이 V3를 뒤집는다.** 최적은 상수(0.2606)가 아니라 **광폭·저기울기
shaped barrier**(0.5244)다. `‖u′‖`와 강건성의 관계는 **비단조**다.
칸토어(0.0500)는 모든 예산에서 하위권이며 폭-정합 shuffle에 2.5배 진다.

**실제 LLM direct test.** 실현 개입 예산을 **±3 % 이내로 정합**하고
지표 도달가능성 게이트를 통과시킨 뒤(공격이 안전도를 0.251 → 0.033으로
떨어뜨림), 6,240행 480 matched 조건에서 동결된 분류기가 자동 판정했다:

| 대조군 | Δ 안전도 | 95 % CI | |
|---|---|---|---|
| **shuffled** | +0.0014 | [−0.0061, +0.0097] | **동등** |
| **center-anchored** | +0.0028 | [−0.0027, +0.0097] | **동등** |
| periodic | −0.0000 | [−0.0062, +0.0061] | 동등 |
| 무제어 | **+0.0285** | [+0.0144, +0.0451] | Cantor 우수 |
| **진짜 상수** | **+0.0181** | [+0.0040, +0.0336] | Cantor 우수 |

```
AUTOMATIC VERDICT: C_PRACTICALLY_EQUIVALENT
```

> **다척도 잔차 장벽 제어는 실제로 작동한다** — 무제어보다 +0.029,
> 진짜 상수 조종보다 +0.018 (둘 다 CI가 0을 배제).
> **그러나 그 이득은 배치와 무관하다.** 폭·에너지를 맞춘 shuffle과
> center-anchored가 칸토어와 사전등록된 SESOI(0.03) 이내로 **동등**하며,
> CI 폭이 ±0.008로 SESOI보다 훨씬 좁아 **동등성이 적극적으로 입증**된다.

## 2–4. V1 · V2 · V3 요약

* **V1** — `g = 1_{K_n}`. `S° ⊂ F_n`이므로 불변성은 δ-무관 항등식.
  측도정합 대조군 대비 백분위 41–52.
* **V2** — 정리 A(level 총작용량 `E₀`)·정리 B(peak `3E₀(3/2)^k`) 증명.
  **둘 다 배치 무관.** 합성에서 cantor < central, < shuffled.
  LLM 실험은 ASR 퇴화로 **미결**.
* **V3** — **정리 S**(`V′_n(T_i(r)) = (3/2)V′_{n−1}(r)`)로 칸토어 고유 성질
  확보. 사영 중점이 median 0.339 σ, max 1.773 σ 이동함을 측정.
  합성에서 칸토어 최하위. **그러나 두 헤드라인이 코드 결함 위에 있었다.**

## 7. 진짜 상수 컨트롤러

`S1_true_constant`: `u(r) ≡ −c`, 모든 `r`·모든 `Δ`에서 **비트 동일**,
`‖u′‖_∞ = 0`. 옛 구현은 `S2_global_smooth`로 보존.
**"state-independence"라는 표현은 `S1`에만 사용한다.**

## 8. V2 calibration 재구성

`C_V2_LAST_PROMPT`(npz의 실제 값) / `C_GLOBAL_POOLED` / `C_PHASE` /

## 9. 사영 중점 vs behavioral boundary

V3가 측정한 `τ_mid`는 사영 분포의 중점이지 행동적 거부 경계가 아니다.
**용어를 "projection midpoint non-stationarity"로 후퇴**한다.
behavioral boundary 추정은 §31 한계로 남긴다.

## 19–28. LLM direct test

**v1은 STOP D로 무효** — 실현 예산이 9개 중 8개에서 −13 %~−59 % 벗어났다.
원인은 probe 생성 길이(8) ≠ 시험 길이(48)였고, **상태 무관 컨트롤러만
정확히 맞은 것**이 원인의 확증이다. 결과는 삭제하지 않고
`v31_llm_direct_v1_INVALID.csv`로 보존, 판정 규칙과 SESOI는 바꾸지 않았다.

**v2는 정합에 성공**: cantor +0.9 %, shuffled +0.8/+0.2/−0.2 %,
center-anchored +0.7/+2.1/+0.5 %, periodic +2.5 %, true constant +0.0 %.
정합 실패 3개(global smooth +6.6 %, wide central −3.8 %, minimax +5.4 %)는
사전등록 규칙대로 matched 비교에서 **제외**했다.

판정: **`C_PRACTICALLY_EQUIVALENT`** (§1 표 참조).

**유틸리티·일관성.** coherence가 전 컨트롤러에서 **0.998–0.999**로 유지되고
benign 응답 길이 33–34단어. `q_cap = 0.05`가 V2의 출력 붕괴(개입 0.60–0.75,
coherence 0.76)를 구조적으로 막았다. benign false refusal 0.458(무제어)
→ 0.500–0.583(개입) — 개입의 실제 비용이다.

## 29. 동등성 검정

`n = 480` paired, CI 폭 ±0.008 vs SESOI 0.03.
CI가 SESOI 밴드 **안에 완전히 들어가므로** 단순 비유의가 아니라
**동등성이 적극적으로 입증**된다.

## 31. 한계

1. **모델 복제 미완.** Qwen2.5-0.5B 단일. SmolLM2-360M은 거부 행동이 없어
   (0/6) 제외했고, TinyLlama-1.1B는 캐시되었으나 시간 내 미수행.
   따라서 LLM 결론은 **model-specific evidence**다.
2. **주 종점 `R_worst`가 변별력이 없다.** `ε ≥ 5`에서 모든 컨트롤러가
   붕괴하여 9개 중 8개가 정확히 0이다. 정보를 담은 것은 paired 분석이다.
3. **behavioral boundary 미추정.** `P(refusal|z)` 적합과 `τ_beh`는
   수행하지 못했다. 따라서 "안전 경계가 움직인다"가 아니라
   **"사영 중점이 움직인다"**만 주장한다.
4. **평가자**는 lexical + coherence 조합이며 LLM judge가 아니다.
   절대 안전도가 아니라 controller 간 비교만 의미가 있다.
5. **1차원 refusal 가정.** rank-k 부분공간 분석 미수행.
6. **12 harmful goal × 2 템플릿** — paired n은 크지만 goal 다양성은 작다.
7. **mechanism 전체 격자 재실행(D6) 미완.** V3의 축소 격자 결과
   (자기유사성 r = +0.147)를 그대로 인용하며, 그것이 축소 격자임을 명시한다.
8. 3개 baseline이 예산 정합에 실패해 matched 비교에서 제외되었다.

## 32. V1 → V3.1 통합 해석

| | 컨트롤러 | 칸토어 고유 성질 | 결과 |
|---|---|---|---|
| V1 | 이진 마스크 | 없음 | 이점 없음 |
| V2 | 척도보상 장벽 | 정리 A·B — **배치 무관** | 이점 없음 |
| V3 | + 경계 불확실성 | **정리 S — 배치 고유** | 최하위 (단, 코드 결함) |
| **V3.1** | + 진짜 상수·실측 예산·직접 LLM 시험 | 정리 S + **정리 T** | **동등 (C)** |

네 번의 독립적 시도에서, 설계를 정반대로 바꾸고, 칸토어 고유의 정리를 둘
확보하고, 경계 불확실성 축을 도입하고, 실제 LLM에서 예산을 맞춰 직접
검정해도 **같은 답이 나왔다.**

**무엇이 실제로 중요한가:**
1. 개입이 존재하는가 (무제어 대비 +0.029)
2. 상태 의존적인가 (진짜 상수 대비 +0.018)
3. 개입이 선형 영역에 머무는가 (`q_cap`이 출력 붕괴를 막았다)
4. **배치는 중요하지 않다** (shuffle·center-anchored·periodic 전부 동등)

## 33. 결론

> **칸토어의 재귀적 자기유사 배치는, 그것을 제어장에 정확히 보존하는
> 정리(S)를 증명하고 그 민감도를 정량화하는 정리(T)를 세운 뒤에도,
> 실제 LLM 잔차 안전 제어에서 동일 예산의 폭-정합 대조군과
> 실용적으로 구별되지 않는다.**
>
> 작동하는 것은 **상태 의존적 다중척도 개입이 존재한다는 사실 자체**이지
> 그 개입이 칸토어 계층으로 배치되었다는 사실이 아니다.

**세 가지 방법론적 부산물:**
* **주 종점의 도달가능성을 freeze 전에 검증해야 한다.** V2·V3는 각각 한 번씩
  구조적으로 퇴화한 지표로 시험을 돌렸다. V3.1은 게이트를 세워 막았다.
* **해석적 예산이 아니라 실현 예산을 맞춰야 한다.** V2는 6배, V3.1-v1은
  최대 59 % 벗어났다. 상태 무관 컨트롤러만 이 오류에 면역이라는 사실이
  진단의 열쇠였다.
* **개입 크기에 상한을 두고 coherence를 함께 보고해야 한다.** 상한이 없으면
  lexical 안전 지표가 출력 붕괴를 "안전"으로 오독한다.
