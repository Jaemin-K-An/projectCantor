# V3 → V3.1: 왜 닫아야 하는가

V1·V2·V3의 결과는 **삭제하거나 유리하게 다시 쓰지 않는다.**
V3.1은 새 가설을 세우는 단계가 아니라 **남은 confound를 제거하고 결론을
확정하는 closure 단계**다.

## 1. V3가 남긴 것

**유효:**
* **정리 S** — `V′_n(T_i(r)) = (3/2)V′_{n−1}(r)`. V2의 정리 A·B와 달리
  **배치 고유**(폭-정합 대조군 잔차 0.82–0.96 vs 칸토어 10⁻¹³).
* **사영 중점 비정상성** — median 0.339 σ, q95 1.187 σ, max 1.773 σ.
  토큰 위치가 지배적 요인(layer 4에서 prefill −0.603 → 첫 생성 토큰 +1.046).
* 합성에서 칸토어가 좋은 minimax controller가 아님.

**무효 또는 미검증 (V3.1이 고침):**

| # | 문제 | V3.1 |
|---|---|---|
| D1 | `L1_constant`가 상수가 아님 (range 1.5) | `S1_true_constant` 신규 구현 + 옛것 `S2_global_smooth` 보존 |
| D2 | `C0_fixed`가 V2 calibration이 아님 | 4종 분리 재계산 |
| D3 | `τ_mid`를 "safety boundary"라 호칭 | **projection midpoint**로 용어 후퇴 |
| D4 | 정리 S 퍼텐셜 offset 누락 | 정정 |
| D5 | 전역 Corollary S.1 거짓 | 삭제, 국소 S.1′ 증명 |
| D6 | mechanism 축소 격자 | 전체 격자 재실행 |
| D7 | L9 미동결 | `l9_frozen_weights.toml` |
| D8 | LLM direct test 부재 | 수행 |

## 2. V3.1이 새로 확보한 것

**정리 T:** `‖u′_k‖_∞ = 12·E₀·(9/2)^k` (측정/예측 비 1.000000).
평균값 정리로 calibration 이동 민감도 `S_u(Δ) ≤ ‖u′‖_∞|Δ|`.
**진짜 상수 컨트롤러는 `‖u′‖ = 0`이므로 `S ≡ 0`이다.**

이로써 V1→V3.1의 정리 계보가 완성된다:

| 정리 | 내용 | 배치 의존? |
|---|---|---|
| A, B (V2) | 척도 보상, `(3/2)^k` 진폭 | 무관 |
| **S (V3)** | 자기유사 척도 동변성 | **칸토어 고유** |
| S.1′ (V3.1) | 국소 coverage 멱법칙 | 칸토어 고유 |
| **T (V3.1)** | calibration 민감도 `(9/2)^k` | 무관 |

**배치를 구별하는 정리는 S 하나뿐이고, 그 성질은 강건성과 상관이 없다**
(V3: r = +0.147). 강건성을 좌우하는 두 정리(A·B·T)는 모두 배치 무관이다.

## 3. V3.1이 뒤집은 것

합성 재실행 결과 V3의 **"상태 무관성이 최적"이라는 결론이 무효**임이 드러났다.
진짜 상수는 0.2606에 그치고, 최적은 **광폭·저기울기 shaped barrier**
(`S2_global_smooth`, `‖u′‖ = 6`)의 0.5244다.

`‖u′‖`와 강건성의 관계는 **비단조**다:
* `‖u′‖` 매우 큼 (4428.7, 다척도) → 치명적
* `‖u′‖ = 0` (진짜 상수) → 예산 낭비
* `‖u′‖ ≈ 6` (광폭 shaped) → 최적

> 상태에서, 칸토어의 자기유사 배치가 폭-정합 대조군보다 나은가?
