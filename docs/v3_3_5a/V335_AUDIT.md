## 정확히 다시 쓰는 것 — G1 결과의 표현

**쓰면 안 되는 문장:** *"G1은 인과적 효과가 없다."*

G1의 logistic 기울기는 **양수**였고 부트스트랩 구간이 **0을 배제**했다.
정확한 서술은:

> G1-only 인과 레버리지가 자연 잔차 척도 대비 **너무 약하고**, 추정된 50 %
> 전이가 **너무 부정확**하여 동결된 게이트 아래에서 안정적인 행동 경계를
> 지지하지 못했다.

**"인과적 효과가 존재한다"와 "쓸 수 있는 행동 임계가 식별된다"는 다르다.**

| σ_G1 (clean SD) | 0.5613 |
| **β_std** | **0.0199** log-odds/σ |

| slope CI가 0 배제 | **예** |

## 타이밍 문제

거부 방향은 `representations.py:25`의 `last_token_only=True` — 즉
**마지막 프롬프트 토큰(P0)**에서 추정되었다. 그런데 V3.3.5는
**토큰 1이 이미 선택된 뒤**인 G1에서 시험했다.

```
prompt … → [P0] → logits(token 1) → token 1 → [G1] → logits(token 2)
            ↑ forward 0                          ↑ forward 1
```

**G1 개입은 토큰 1을 바꿀 수 없다. P0는 바꿀 수 있다.** 이것이 이 수정의 전부다.
