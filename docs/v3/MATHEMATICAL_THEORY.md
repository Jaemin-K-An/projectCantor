# V3 수학 — 자기유사성 정리

증명과 경험적 관찰을 엄격히 구분한다. `scripts/v3/`가 수행하는 것은
구현이 정리를 위반하지 않는지 확인하는 회귀시험이지 증명이 아니다.

## 0. 설정 (V2에서 이어받음)

level `k`의 gap `N_k = 2^{k-1}`개, 폭 `w_k = 3^{-k}`, 에너지 `e_k = E₀/2^{k-1}`,
smoothstep `Φ(u) = 3u²−2u³`,

    V_n(r) = Σ_k Σ_j e_k Φ((r−a_{k,j})/w_k),   u_C = −V_n′ ≤ 0.

**정리 A** (level 총작용량 `= E₀`)와 **정리 B** (`‖V′_k‖_∞ = 3E₀(3/2)^k`,
비 `3/2`)는 V2에서 증명되었고 **폭-정합 배치 전부가 동일하게 만족한다.**

---

## 1. 정리 S — 칸토어 장벽장의 정확한 척도 동변성

칸토어 IFS의 두 수축사상을

    T₀(r) = r/3,      T₂(r) = 2/3 + r/3

라 하자.

> **정리 S.** 모든 `r ∈ [0,1]`과 `i ∈ {0,2}`에 대하여
>
>     V′_n(T_i(r)) = (3/2)·V′_{n−1}(r)
>     V_n(T_i(r)) − V_n(T_i(0)) = (1/2)·V_{n−1}(r)

**증명.** `[0,1/3]` 안에 놓인 level-`n` 구성의 gap 전체는, `[0,1]` 위
level-`(n−1)` 구성의 gap 전체의 `T₀`-상과 정확히 일치한다: level `k`의
gap `(a, a+w_k)`는 `(a/3, a/3 + w_k/3)`로 옮겨가고 이는 level `k+1`이며
실제로 `w_{k+1} = 3^{-(k+1)} = w_k/3`이다. 그 에너지는
`e_{k+1} = E₀/2^k = e_k/2`.

gap 내부에서 장은 `(e/w)Φ′((r−a)/w)`이고, 정규화 좌표는

    (T₀(r) − T₀(a)) / (w_k/3) = (r−a)/w_k

로 **불변**이므로 `Φ′` 인자는 바뀌지 않는다. 따라서 진폭만

    (e_k/2)/(w_k/3) ÷ (e_k/w_k) = 3/2

배가 된다. gap 밖에서는 양변이 0이다. `T₂`에 대해서도 상은 `[2/3,1]`이며
동일한 논증이 그대로 적용된다. 적분하면

    V_n(T_i(r)) − V_n(T_i(0)) = ∫₀^r (3/2)V′_{n−1}(u)·(1/3) du = (1/2)V_{n−1}(r). ∎

**수치 확인** (`src/v3/CantorSelfSimilarity.jl`): `n = 3…8`에서 상대 L2 잔차
`3.6×10⁻¹⁵ … 7.1×10⁻¹³`.

### 1.1 **정리 S는 배치 불변이 아니다** — 이것이 V2와의 결정적 차이

폭·level·에너지 multiset을 정확히 보존한 대조군의 상대 잔차 (n = 6, 6 seed):

| family | median | min |
|---|---|---|
| **B7_cantor** | **0.0000** | 0.0000 |
| B3_periodic | 0.9611 | 0.9611 |
| B6_center_anchored | 0.9285 | 0.8623 |
| B4_random | 0.9235 | 0.8299 |
| B5_shuffled | 0.9009 | 0.8203 |

> **정리 A·B는 칸토어를 구별하지 못하지만 정리 S는 구별한다.**
> V3에서 처음으로 칸토어 고유의 수학적 성질을 확보했다.

### 1.2 따름정리 S.1 — 자기유사 coverage

`M_n(Δ) = min_r max_{|u−r|≤Δ} V′_n(u)`라 하면 정리 S로부터 부분복사본 위에서

    M_n(Δ/3) = (3/2)·M_{n−1}(Δ)

즉 칸토어 배치의 coverage 곡선은 `Δ`의 **정확한 멱법칙**이다. 폭이 같은
shuffle에는 그런 관계가 없다.

**로버스트 제어에서의 의미.** 경계 오차 `Δ`는 컨트롤러가 `r` 대신 `r+Δ`에서
장을 평가하게 만든다. 정리 S는 칸토어 장이 "모든 척도에서 같아 보인다"는
뜻이므로, 이동에 대한 응답이 척도에 대해 공변(covariant)이다. **재귀적
배치가 미지의 `Δ`에 대해 강건성을 살 수 있는 유일한 메커니즘이 이것이다.**

## 2. 그 메커니즘은 실제로 작동하는가 — **아니다**

정리 S는 성질의 **존재**를 확립할 뿐 그것이 강건성을 만든다는 것을
증명하지 않는다. 이는 경험적 질문이며 PHASE 6b가 답한다.

82개 배치(칸토어 1 + shuffled 40 + center-anchored 40 + periodic 1)에 대해
실현 예산을 맞춘 뒤 worst-case 강건성과 기하 통계를 회귀했다.

| 기하 통계 | Pearson r vs `R_worst` |
|---|---|
| **self-similarity (정리 S 점수)** | **+0.147** |
| **max_weak_run** (최장 무방비 구간) | **−0.680** |
| mean nearest-barrier | −0.608 |
| discrepancy | −0.412 |
| max_gap_span | −0.080 |
| level entropy | +0.000 |

칸토어는 정리 S에 의해 self-similarity = **1.000**이고 모든 대조군은
0.055–0.266인데, 칸토어의 `R_worst`는 대조군 분포의 **35.8 백분위**다.

> **자기유사성 메커니즘은 기각된다.** 강건성을 예측하는 것은
> **최장 무방비 구간의 길이**, 즉 평범한 coverage 균일성이며,
> 잘 퍼진 배치라면 무엇이든 달성한다.
