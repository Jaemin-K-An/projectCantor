# V2 → V3: 왜 다시 묻는가

**V1·V2의 negative result를 삭제하거나 약화하지 않는다.**

## 1. V2가 남긴 것

* **정리 A·B는 참이지만 배치 무관하다.** 폭-정합 대조군이 동일하게 만족하므로
  Cantor 우수성의 근거가 될 수 없다. (증명)
* **합성 동역학에서 H3·H4 기각.** cantor < shuffled(−0.038), cantor < central
  (−0.081), cantor ≈ center-anchored(`d_z` 0.049). (경험적)
* **LLM 실험은 미결.** 주 종점이 구조적으로 퇴화하여
  (`compliance ≤ 24/60 < 0.5`) 어느 방향으로도 결론을 지지하지 않는다.
  전문: [`V2_LLM_AUDIT.md`](V2_LLM_AUDIT.md).

## 2. V2가 암묵적으로 가정한 것 — 그리고 그것이 거짓인 이유

V2의 모든 장벽 컨트롤러는 **판정 경계가 정확히 `r = 1/2`에 있다**고 가정했다.
칸토어·center-anchored 배치의 level-1 gap을 거기 놓는 것이 설계의 핵심이었다.

그러나 V2는 `τ_ℓ, σ_ℓ`를 **마지막 프롬프트 토큰**에서 추정한 뒤
prefill과 모든 생성 토큰에 적용했다. 그 경계가 실제로 얼마나 움직이는지는
**측정되지 않았다.**

PHASE 3에서 측정한 결과 ([`BOUNDARY_SHIFT_ANALYSIS.md`](BOUNDARY_SHIFT_ANALYSIS.md)):

| \|Δ_norm\| | median | q90 | q95 | max |
|---|---|---|---|---|
| | **0.339 σ** | 0.930 σ | **1.187 σ** | **1.773 σ** |

layer 4에서 prefill(−0.603 σ)과 첫 생성 토큰(+1.046 σ) 사이의 도약은
**1.65 σ**다. `γ ≈ 0.7`에서 이는 threat 좌표를 약 **0.17** 이동시키며,
level-1 gap 폭 `1/3`의 **절반**에 해당한다.

> **따라서 V2의 LLM 실험은 "경계가 알려진" 조건에서의 검정이 아니었다.**

## 3. V3의 재정의

문제를 다음으로 바꾼다.

> 안전 판정 경계의 **위치** `Δ`와 공격 **크기** `ε`가 동시에 불확실할 때,
> 동일한 **실현** intervention budget에서
> Cantor의 재귀적 자기유사 배치가 강한 matched control보다
> **worst-case** robustness를 높이는가?

이 재정의가 V3에 세 가지를 요구한다.

1. **경계를 확률변수로 다룰 것** → PHASE 3·4
2. **실현 예산을 맞출 것** (해석적 `B_total`이 아니라 `‖Δh‖/‖h‖`) → PHASE 8
3. **평균이 아니라 최악을 볼 것** → minimax `J(L)`

## 4. V3가 새로 확보한 것

**정리 S** (`MATHEMATICAL_THEORY.md`): `T₀(r)=r/3`, `T₂(r)=2/3+r/3`에 대해

    V'_n(T_i(r)) = (3/2)·V'_{n-1}(r),    V_n(T_i(r)) = (1/2)·V_{n-1}(r)

**정리 A·B와 달리 이것은 배치 불변이 아니다.** 폭-정합 대조군의 상대 잔차는
0.82–0.96이고 칸토어만 `10⁻¹³`이다. V3에서 처음으로 **칸토어 고유의
수학적 성질**을 확보했다.

남은 질문은 하나다: **그 성질이 강건성을 만드는가?**
