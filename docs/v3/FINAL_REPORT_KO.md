# 안전 판정 경계 불확실성 하에서의 언어모델 잔차 상태 다중척도 제어: 칸토어 구조 기반 분석

*Safety-Boundary Uncertainty and Multiscale Residual Control in Language
Models: A Cantor-Based Study*

> **제목에 관하여.** §57의 "CantorGuard: Self-Similar Robust Residual Control"은
> Cantor-specific positive가 확인된 경우에만 쓸 수 있다.
> **확인되지 않았으므로** 중립 제목을 사용한다.

## 1. 초록

V1은 칸토어 도함수를 정규화한 **이진 게이트**에서, V2는 척도 정보를 복원한
**척도보상 장벽**에서 각각 칸토어 고유의 이점을 찾지 못했다. 그러나 V2의 LLM
실험은 주 종점이 구조적으로 퇴화하여(§4) **어느 방향으로도 결론을 지지하지
못했고**, 더 근본적으로 **판정 경계가 정확히 알려져 있다고 가정**했다.

V3는 그 가정을 검증하고 제거한다.

**측정.** 실제 LLM에서 안전 판정 경계는 층·토큰 위치·생성 단계·공격 계열에 따라
중앙값 **0.34 σ**, 95 백분위 **1.19 σ**, 최대 **1.77 σ** 이동한다. layer 4에서
마지막 프롬프트 토큰과 첫 생성 토큰 사이의 도약은 **1.65 σ**이며, 이는 threat
좌표로 약 0.17 — 칸토어 level-1 gap 폭의 **절반**이다. **V2의 고정 calibration은
이 이동을 무시했다.**

**증명.** 정리 S: `V′_n(T_i(r)) = (3/2)V′_{n−1}(r)`. **V2의 정리 A·B와 달리
배치 불변이 아니다** — 폭-정합 대조군의 잔차는 0.82–0.96, 칸토어는 10⁻¹³.
V3에서 처음으로 **칸토어 고유의 수학적 성질**을 확보했다.

**검정.** 실현 개입 예산을 **±2 %로 정합**한 뒤(V2는 6배 차이) 41,472회
시뮬레이션으로 (경계 오차 Δ) × (공격 크기 ε) 합동 불확실성에서 minimax
강건성을 측정했다. 결과:

| controller | R_worst (budget 0.60) |
|---|---|
| **L1_constant** | **0.524** |
| L9_minimax (학습) | 0.524 |
| L3_wide_central | 0.439 |
| L2_narrow_central | 0.236 |
| L6_shuffled | 0.104 |
| L7_center_anchored | 0.055 |
| **L8_cantor** | **0.050** |
| L0_none | 0.044 |

**경계 불확실성 하에서 칸토어는 모든 컨트롤러 중 최악이며 무제어 바로 위다.**

**메커니즘.** 82개 배치 회귀에서 강건성과 **자기유사성의 상관은 +0.147**로
사실상 없다(칸토어는 자기유사성 1.000이면서 대조군 분포의 35.8 백분위).
강건성을 예측하는 것은 **최장 무방비 구간**(r = −0.680)과 평균 최근접 장벽
거리(−0.608) — 평범한 coverage 균일성이다.

> **결론: 정리 S는 참이지만 강건성과 무관하다.
> 경계 위치가 불확실할 때 최선의 귀납 편향은 다중척도 구조가 아니라
> 상태 무관성(state-independence)이다.**

  ≈ center-anchored(`d_z` 0.049).

## 5. V3 연구 동기와 질문

> 안전 판정 경계 위치 `Δ`와 공격 크기 `ε`가 **동시에 불확실**할 때,
> **동일한 실현 개입 예산**에서 칸토어의 재귀적 자기유사 배치가
> 강한 matched control보다 **worst-case** 강건성을 높이는가?

세 가설을 분리한다: **H-MULTISCALE**(다척도 > 단일척도),
**H-DISTRIBUTED**(분산 배치 > 집중), **H-CANTOR**(재귀적 순서 자체의 이득).
앞의 둘이 참이어도 Cantor-specific 결과가 아니다.

## 6–7. 잔차 안전 좌표와 인과 검증

`z = ⟨h,v⟩`, `m = (z−τ)/σ`, `r = sigmoid(−γm)`. V2에서 Qwen2.5-0.5B layer 13의
refusal direction이 **인과적**임을 확인했다(`+v` 0.625→0.875, `−v` →0.375).
V3는 그 방향을 그대로 쓰되 **`τ`를 상수가 아니라 확률변수로 다룬다.**

## 12–13. 칸토어 자기유사성과 다척도 제어 이론

전문 [`MATHEMATICAL_THEORY.md`](MATHEMATICAL_THEORY.md).

**정리 S.** `T₀(r)=r/3`, `T₂(r)=2/3+r/3`에 대해

    V′_n(T_i(r)) = (3/2)·V′_{n−1}(r),   V_n(T_i(r)) = (1/2)·V_{n−1}(r)

증명은 `[0,1/3]`의 gap 집합이 `[0,1]` level-(n−1) gap 집합의 `T₀`-상이라는
사실과 `e_{k+1}=e_k/2`, `w_{k+1}=w_k/3`에서 직접 따른다. 잔차 `10⁻¹³`.

**배치 불변이 아니다:** periodic 0.961, center-anchored 0.929, random 0.924,
shuffled 0.901 — 칸토어만 0.000.

## 14–18. 불확실성 모형·합성 실험·baseline·예산 정합

* `Δ` 격자 `[−0.155 … 0.155]`: **`3^{-k}`에 정렬하지 않도록** 사전 선택,
  범위는 LLM 실측 q90(0.930 σ ≈ 0.155 in `r`)에 맞춤.
* `ε`: log-spaced 0.30–7.94, 3의 거듭제곱 비정렬.
* baseline 11종에 **L3 wide-central**과 **L9 minimax**(같은 목적함수로 명시
  최적화, 137 후보 + 좌표 정제) 추가.
* **실현 rms 작용량을 이분탐색으로 ±2 % 정합** — V3의 primary fairness constraint.

## 19–20. 지표 검증과 사전등록

**두 번째 지표 퇴화를 사전에 검출했다.** 이진 `P(never crossed)`는 셀의 45 %가
정확히 0, 40 %가 1이며 `ε ≥ 4.13`에서 무제어 포함 전부 0 → 최소값이 모두 0.
graded `safe_frac`(범위 [0.024, 1.000], 0인 셀 없음)으로 교체했고,
**controller 비교를 보기 전 지표 분포만 보고** 결정했음을
`configs/v3/synthetic.toml`에 기록했다.

## 30. 모델 복제

**미완.** Qwen2.5-0.5B에서만 경계 이동을 측정했다. SmolLM2-360M은 거부 행동이
없어(0/6) 제외했고, TinyLlama-1.1B는 내려받았으나 시간 안에 복제하지 못했다.
**따라서 LLM 측정은 model-specific evidence다.**

## 31. 실패한 가설

1. **H-CANTOR 기각.** 자기유사성 상관 +0.147, 백분위 35.8.
2. **H-MULTISCALE도 이 조건에서 기각.** 다척도 전체(L4–L8)가 단일척도·상수에 패배.
3. **정리 S는 참이지만 쓸모없다.** 칸토어 고유 성질을 처음 확보했는데
   강건성과 무관했다.
4. **예상 밖:** 경계 불확실성이 다척도 구조를 **돕지 않고 처벌한다.**
   상태 의존 컨트롤러만 `Δ`에 노출되기 때문이다.
5. **L9 minimax가 비균일 최적해를 찾았다** — 초기 60후보 탐색은 균일해로
   수렴했으나(약한 탐색) 137후보+정제에서 0.4613 → 0.5225.

## 32. 한계

1. **LLM controller 시험 미완.** V3는 LLM에서 **경계 이동과 calibration**만
   측정했고, 11개 controller의 Δ×ε 시험은 **합성 모형에서만** 수행했다.
   합성의 Δ 범위를 LLM 실측 q90에 맞췄으나 **LLM 직접 검정은 아니다.**
2. **단일 모델·단일 규모** (0.5B, 8 GB / 3.4 GB 환경 제약).
3. **1차원 refusal 가정** — Wollschläger et al.(2025)의 concept cone 미검토.
4. **경계 이동의 인과성 미확인** — `τ` 이동이 실제 행동 변화에 대응하는지는
   측정하지 않았다(사영 분포의 이동만 측정).
5. **합성 모형의 f는 3종**이며 실제 잔차 동역학의 대리물일 뿐이다.
6. **coherence·utility 삼중 평가 미완** (LLM controller 시험 미완의 귀결).

## 33. V1 → V2 → V3 통합 결론

| | 컨트롤러 설계 | 칸토어 고유 성질 | 결과 |
|---|---|---|---|
| **V1** | 이진 마스크 `1_{K_n}` | 없음(정규화로 소실) | 이점 없음 |
| **V2** | 척도보상 장벽, gap 내부 | 정리 A·B — **배치 불변** | 이점 없음 |
| **V3** | 동일 + 경계 불확실성 | **정리 S — 배치 고유** | **이점 없음, 오히려 최악** |

세 번의 독립적 시도에서, 설계를 정반대로 바꾸고(마스크→장벽, `K_n` 위→gap 안),
칸토어 고유의 정리를 확보하고, 경계 불확실성이라는 새로운 축을 도입해도
**같은 답이 나왔다.**

**무엇이 실제로 중요한가:**

1. **경계를 덮는가** (V1·V2)
2. **경계 위치를 잘 아는가** (V3: 동적 calibration이 오차 29 % 감소)
3. **경계를 모를 때는 상태 무관성** (V3: 상수 조종이 minimax 최적)
4. **coverage 균일성** (V3: r = −0.680), 자기유사성 아님 (r = +0.147)

## 34. 결론

> **칸토어 계단 함수의 재귀적 자기유사 구조는, 그것을 제어장에 정확히
> 보존하는 정리를 증명한 뒤에도, 안전 제어 문제에서 측정 가능한 이점을
> 제공하지 않는다.**
>
> 경계 위치가 불확실할 때는 오히려 **해가 된다** — 미세한 상태 의존 구조일수록
> 경계 오차에 크게 노출되기 때문이다. 그 조건에서 minimax 최적 전략은
> **상태 무관한 상수 조종**이다.

가장 실용적인 부산물 두 가지:

* **LLM의 안전 판정 경계는 정상적(stationary)이지 않다.** 토큰 위치만으로도
  1.65 σ 이동한다. **고정 임계값을 쓰는 모든 activation-steering 안전 기법은
  이 이동을 보고해야 한다.**
* **주 종점의 도달가능성을 freeze 전에 검증해야 한다.** V2와 V3에서 각각
  한 번씩 지표가 구조적으로 퇴화했고, V3에서는 사전에 잡았다.
