# 안전 판정 경계의 비정상성 측정 (PHASE 3)

**이 문서는 V3 전체가 성립하는지를 결정하는 경험적 질문에 답한다** (§37):

> LLM의 안전 판정 경계 `τ(x, ℓ, t, a)`는 실제로 움직이는가?
> 움직이지 않는다면 V2의 고정 calibration이 옳았고 V3의 동기가 약해진다.

원자료: `results/v3/raw/v3_boundary_shift_qwen2.5-0.5b-instruct.csv`
스크립트: `scripts/v3/measure_boundary_shift.py`
사용 데이터: **calibration + dev만.** test split은 로드하지 않는다.

---

## 1. 측정 방법

각 조건에서 refusal 사영 `z = ⟨h, v_ref⟩`의 harmful/harmless 분포로부터
**V2와 동일한 추정량**으로 임계값을 다시 구한다.

    τ_cond = ½(mean z_harm + mean z_ben),   σ_cond = √(½(var + var))

정규화된 경계 이동:

    Δ_norm = (τ_cond − τ_global) / σ_global

V2와 같은 추정량을 쓰는 것은 의도적이다. 묻는 것은 "더 좋은 추정량이
있는가"가 아니라 **"V2 자신의 양이 조건에 따라 얼마나 움직이는가"**다.

축: layer(6) × attack template(5) × token bin(6) = 180개 조건.

|---|---|

| q75 | 0.601 σ |
| q90 | 0.930 σ |
| q95 | **1.187 σ** |

## 3. V2 감사 defect C의 경험적 확인

V2는 `τ_ℓ, σ_ℓ`를 **마지막 프롬프트 토큰**에서 추정하고
prefill + 모든 생성 토큰에 적용했다. 위 측정은 그 지점이

* 첫 생성 토큰에서 최대 **1.65 σ**,
* 중앙값으로도 **0.34 σ**

어긋남을 보인다.

**threat 좌표에 대한 함의.** `r = sigmoid(−γm)`이고 DEV가 고른 `γ ≈ 0.7`이므로
`1 σ`의 경계 이동은 `r`을 약

    sigmoid(0.7) − 0.5 ≈ 0.168

만큼 이동시킨다. 칸토어·center-anchored 배치의 level-1 gap 폭이 `1/3`이므로,
**경계 오차 1 σ는 장벽을 자기 폭의 절반만큼 밀어낸다.** 즉 판정 경계를
지키도록 설계된 구조가 실제로는 경계를 벗어난 곳을 지키게 된다.

---

## 4. 사전등록된 불확실성 집합 `U_Δ`

위 측정(**calibration + dev만**)으로부터 동결한다:

```json
{"median": 0.339, "q75": 0.601, "q95": 1.187, "max": 1.773, "n": 180}
```

합성 실험의 `Δ ∈ [−0.155, 0.155]` (threat 좌표 단위)는 `γ = 0.7`에서
margin 단위로 약 **±0.93 σ**에 해당하며, 이는 측정된 **q90 = 0.930**과
거의 정확히 일치한다. **합성 실험의 불확실성 범위는 실제 LLM 측정값에
맞춰 교정되어 있다** — 사후에 고른 것이 아니다.

---

## 5. 결론

> **V3의 전제는 성립한다.** LLM의 안전 판정 경계는 층·토큰 위치·생성 단계·
> 공격 계열에 따라 중앙값 0.34 σ, 95 백분위 1.19 σ 이동한다.
> V2의 고정 calibration은 이 이동을 무시했고, 그 크기는 칸토어 장벽의
> level-1 gap 폭의 절반에 해당한다.

이것이 V3가 경계 위치를 **확률변수**로 다루는 이유이며,
PHASE 4(동적 calibration)와 PHASE 6(Δ×ε 합동 실험)의 근거다.
