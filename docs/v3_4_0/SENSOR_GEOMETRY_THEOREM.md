# 정리 S와 잔차 인증서

## 정리 S (1-Lipschitz)

`f(h) = w^T h + b`, `d(h) = f(h)/||w||`에 대해 임의의 섭동 `dh`는

    d(h + dh) - d(h) = w^T dh / ||w||

를 준다. Cauchy–Schwarz에 의해

    |dd| <= ||dh||_2

이고 **상수는 정확히 1**이다. 또한 `dh = eps * w_hat`이면

    |dd| = eps

로 **등호가 성립한다.** 즉 이 경계는 sensor 법선 방향에서 타이트하다.

수치 검증: 500개 무작위 섭동에서 slack `||dh|| - |dd| >= 0` 위반 0건,
`w_hat` 방향에서 slack = 0 (1e-9 이내), 초평면 위 점에서 `|d| < 1e-15`.

## 아핀 좌표

고정 window `W`에 대해

    r(d) = 1/2 - d/(2W)

이면 `d = 0`이 `r = 1/2`로 가고

    |dr| = |dd| / (2W).

`W`는 `D_window_cal`에서 `W = 1.05 * Q_0.99(|d(h_clean)|)`로 한 번 정하고
**모든 rho에 같은 값**을 쓴다. window 밖은 외삽하거나 clip하지 않고
`OUTSIDE_WINDOW`로 보수적 fallback한다.

실측: **W = 2.2805**.

## 정리 C-SENSOR (잔차 인증서)

깊이 3 대칭 재귀 분할에서 서로 다른 terminal 영역 사이의 직접 전이는

    |dr| >= M_3(rho) = rho^2 (1 - 2 rho)

를 요구한다. 정리 S와 아핀 사상을 결합하면

    |dr| <= ||dh||_2 / (2W)

이므로 충분조건

    ||dh||_2 < 2W * rho^2 (1 - 2 rho) =: epsilon_h(rho)

를 얻는다. `M_3' = 2 rho (1 - 3 rho)`이므로 `(0, 1/2)`에서 유일한 최대점은
`rho = 1/3`이고

    epsilon_h(1/3) = 2W/27 = 0.1689.

## 왜 이것이 V3.3.5c보다 강한가

V3.3.5c의 좌표는 **구동 방향 위의 사영**이었다. 여기서는 좌표 자체가
경험적으로 학습된 행동 초평면까지의 **유클리드 거리**다. 따라서
`epsilon_h`는 "sensor-정책 영역 사이의 직접 전이를 막는 데 충분한 잔차 공간
반경"으로 직접 해석된다.

## 이 정리가 아닌 것

- 보편적 LLM 안전 인증서가 **아니다**.
- semantic jailbreak 방어 보장이 **아니다**.
- 학습된 sensor, 이 모델/layer/P0 정의, 고정 `W`, 정의된 정책 기하에
  **조건부**다.
- 실제 공격에서 위반 0건이 나와도 그것은 해석적 정리의 **구현 검증**이지
  독립적인 의미 안전성 증거가 아니다.

또한 이 기하는 **controller 설계**이지 모델에서 발견한 성질이 아니다.
LLM이 프랙탈 구조를 갖는다고 주장하지 않는다.
