# 감지-구동 분리 가설

## 상태

    h in R^896      layer 14, P0 (마지막 유효 프롬프트 토큰, 토큰 1 직전)

## 두 역할

**SENSOR** — 행동 안전 상태를 추정한다.

    f(h) = w^T h + b
    d(h) = (w^T h + b) / ||w||_2

`d(h)`는 학습된 결정 초평면 `w^T h + b = 0`까지의 **부호 있는 유클리드
거리**다. 로짓을 그대로 좌표로 쓰지 않고 `||w||`로 정규화하는 것이 핵심이다.
그래야 좌표가 잔차 공간의 실제 거리 단위를 갖는다.

**ACTUATOR** — 행동을 인과적으로 움직인다.

    delta_h = eta * v_safe,     ||v_safe|| = 1

## 결합

    kappa = <w_hat, v_safe>

controller가 `eta`만큼 밀면 sensor는 **정확히** `eta * kappa`만큼 움직인다.
이 스칼라 하나가 두 역할을 잇는 유일한 접점이다.

## 실측값

| 양 | 값 |
|---|---|
| `cos(w, v)` | **+0.3102** |
| `angle(w, v)` | **71.9°** |
| `kappa` (safe 방향) | **+0.3102** |

**두 방향은 71.9° 떨어져 있다.** 가설이 예측한 대로 `w != v`다.
부호가 양수라는 점도 중요하다 — 독립적으로 학습된 sensor와 역사적 actuator가
"어느 쪽이 안전한가"에 대해 서로 동의한다.

## 직접 비교 (D_sensor_confirm, n=85)

| 지표 | OLD `<h,v>` | NEW `d_w` |
|---|---:|---:|
| AUROC | 0.8557 | **0.9336** |
| PR-AUC | 0.9163 | **0.9717** |
| balanced accuracy | 0.7669 | **0.8656** |
| Brier | 0.1459 | **0.1303** |

짝지은 bootstrap AUROC 차이: **+0.0780 [+0.0029, +0.1660]**, 20,000회 중
97.9 %에서 새 sensor가 우세. 두 좌표 모두 D_sensor_train에서만 적합했고
confirm은 한 번만 읽었다.

**큰 AUROC 격차 + 작은 `|cos(w,v)|`** — 이것이 가설의 직접적 서명이다.

## 왜 경계 식별 문제가 사라지는가

V3.3.5c는 사후에 `tau = -a/b`를 추정해야 했고 그 CI가 18 sigma였다.
여기서는 경계가 **구성상 `d = 0`**이다. 추정할 스칼라가 없다.
질문이 "문턱이 어디인가"에서 "초평면이 새 프롬프트로 일반화되는가"로 바뀌며,
후자는 통계적으로 훨씬 잘 정의된다.
