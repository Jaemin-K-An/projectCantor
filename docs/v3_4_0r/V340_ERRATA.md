# V3.4.0 정오표

원본 파일은 수정하지 않는다. 아래는 **인용 시 대체해야 할 문장**의 목록이다.

## 1. `GENERATION = GEN2_RHO_FAMILY_PRACTICALLY_EQUIVALENT`

**대체**: `GEN6_EQUAL_BUDGET_COMPARISON_BLOCKED`.

같은 실행이 `confirmatory_comparison_blocked = true`와 `all_matched = false`를
기록했다. 예산이 정합되지 않은 arm 사이의 동등성은 주장할 수 없다.
`OVERALL = G_INCONCLUSIVE`는 그대로 유효하다.

## 2. "행동 실패는 인증 반경의 11–70배에서 일어난다"

62–82 %가 우측 절단된 상태에서 **관측 사건만의** 중앙값이었다. 모집단 중앙값이 아니다.

**대체**:

> 시험 격자 안에서 행동 실패가 관측된 프롬프트에 한해, 관측된 실패 크기는
> 해석적 인증서보다 통상 훨씬 컸다. 다만 62–82 %가 우측 절단되었으므로
> 모집단 실패 반경의 중앙값은 확립되지 않았다.

## 3. "controller가 행동적으로 무력하다"

V3.4.0의 증거는 **rho 사이의 출력이 거의 동일**하다는 것이었다(출력 차이 1.5 %,
라벨 차이 0.07 %). 그것은 `CANTOR_RHO_DIFFERENTIATION_WEAK`를 지지하지만
`DEFENCE_EFFECT_ZERO`를 지지하지 않는다. attacked no-controller 기준선이 없었기
때문이다.

**대체**: "matched-budget rho 사이의 차이가 관측되지 않았다." 무력함 주장은
V3.4.0R의 `CTRL` 판정에서만 가능하다.

## 4. "감지=구동이 이전 실패의 원인이었다"

**대체**: "하나의 잔차 방향에게 두 역할을 동시에 시키는 것은 중요한 실패
양식이었고, 따로 학습한 선형 sensor가 상당히 잘 일반화했다." 유일 인과 주장은
이 실험이 식별하지 않는다.

## 5. `q_cap = 0.05`

선언되었을 뿐 강제되지 않았다. 실제 `q_max`는 rho=0.44에서 0.0554였다.
V3.4.0의 "예산 상한 안에서" 류의 서술은 상한이 실제로 지켜졌다는 뜻이 아니다.

## 6. `d = 0`

"행동 경계"가 아니라 **재가중 분류기의 결정 초평면**이다.
