## 2. 계수 규칙 — 대조군에 공정하게

순진한 서사는 *"칸토어는 O(n), 나머지는 O(2^n)"*이라고 말한다. **이 서사는
틀렸고**, 그대로 두면 이 연구가 피하려는 바로 그 종류의 결과가 된다.

**seeded shuffle은 칸토어 간극 multiset의 치환이고, 치환은 multiset을
보존한다.** 따라서 P1–P5는 shuffle에서도 **똑같이 싸게** 증명된다.
이들을 shuffle에 비싸게 계상하지 않는다.

분리되는 것은 **위치 의존** 성질뿐이다:

* **P6**은 비재귀 layout에서 *비싼 것이 아니라 **거짓***이다.
* **P8**만이 실제로 비용이 든다 — 성분 간 구조 관계가 없으면 전수 방문이 필요하다.

## 3. 두 검증 방식

**귀납적(inductive)** — 재귀 family:
base case + 준위당 1 보조정리 + 아핀 보존 보조정리. `O(n)` 의무, `O(n)` 방문.

**열거적(enumerative)** — 구조 관계가 없는 layout:
성분마다 방문. `Θ(2^n)` 의무.

## 4. 재귀 인증 정리 (후보)

`P`가 (i) 아핀 켤레 하에서 보존되고, (ii) 진폭 재척도 `α` 하에서 보존되며,
(iii) 서로소 복사본에 대해 compositional이면,

`C_n = F(C_{n−1})`에 대한 `P(C_n)` 검증은

```
중앙 성분 base case  +  P(C_{n−1}) 재사용 1회  +  아핀 보존 보조정리
```

로 환원되고, proof-schema 복잡도는 depth에 대해 `O(n)`이다.

## 5. 손상 거부 (실측)

좌표 이동 / 폭 변경 / 준위 위조 / 성분 누락 / 구간 중첩 — **5종 전부 거부**.
shuffled layout에 칸토어 재귀 인증서를 주면 `P6`에서 **거짓으로 통과하지 않는다.**

## 6. 실측 의무 수 (n = 20)

| family | 봉인 계수 | **post-hoc 정정** |
|---|---|---|
| `cantor_recursive` | 125 | 125 |
| `recursive_non_cantor` | 125 | 125 |
| `periodic_procedural` | 3,145,805 | **104** |
| `shuffled_seeded` | 3,145,805 | 3,145,805 |
| `center_anchored_seeded` | 3,145,805 | 3,145,805 |
| `shuffled_explicit` | 3,145,805 | 3,145,805 |
| `learned_minimax_explicit` | 7,340,024 | 7,340,024 |

**post-hoc 정정의 이유**: 봉인된 모델은 `periodic`을 열거적 분기에 넣어
`Θ(2^n)` 의무를 부과하면서 동시에 `O(1)` point query를 인정했다 — **모순이며,
대조군을 과소평가한다(즉 칸토어에 유리한 방향의 오류다).**

`L3_periodic`은 간극을 `(준위, 위치)`로 정렬해 고정 간격으로 배치하므로
준위 k까지의 폭 누적합 `S_k = Σ_{i≤k} 2^{i−1}3^{-i}`가 **닫힌 형식**이다.
따라서 주소 사상은 칸토어의 삼진 하강과 마찬가지로 `O(n)` 닫힌 형식이고,
구조 성질도 같은 기호적 처리를 받을 자격이 있다.

정정 후 **`periodic`(104)이 칸토어(125)보다 오히려 싸다.**
