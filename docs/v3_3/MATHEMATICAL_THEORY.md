## 2. 일반 재귀 장벽 이론 (V3.3 신규)

`b`개의 비율 `ρ` 아핀 축약, 상 disjoint, `bρ < 1`.

| 양 | 일반식 | 칸토어 `(b,ρ)=(2,1/3)` |
|---|---|---|
| 준위 1 간극 폭 | `g = (1−bρ)/(b−1)` | `1/3` |
| 준위 k 간극 수 | `N_k = (b−1)b^{k−1}` | `2^{k−1}` |
| 준위 k 간극 폭 | `w_k = ρ^{k−1}g` | `3^{-k}` |
| 간극당 에너지 | `e_k = E₀/N_k` | `E₀/2^{k−1}` |
| 첨두 | `1.5·e_k/w_k` | `3E₀(3/2)^k` ✓ 정리 B |
| 기울기 | `6·e_k/w_k²` | `12E₀(9/2)^k` ✓ 정리 T |
| **장 척도** | **`α = 1/(bρ)`** | `3/2` ✓ 정리 S |
| 퍼텐셜 척도 | `1/b` | `1/2` |
| 민감도 척도 | `1/(bρ²)` | `9/2` |

**정리 A·B·S·T가 모두 특수 경우로 복원된다** (수치 검증: 표시 자릿수 전부 일치).

> 이 일반화의 목적은 칸토어를 약화시키는 것이 아니라 **"왜 하필 칸토어인가"**를
> 엄밀히 묻기 위함이다. 칸토어가 특별하다면 이 family 안에서 특별한 위치를
> 차지해야 한다.

## 3. 기호적 평가 정리 (Symbolic Evaluation Theorem)

**주장.** 차수 `n`의 칸토어 장벽 제어는 `2^n − 1`개 구간을 **materialise하지
않고** 임의의 `r`에서 `O(n)` 시간, `O(1)` 보조 저장으로 평가된다.

**구성.** `r`의 삼진 주소를 하강한다. 준위 `k`에서 셀 `[p/3^{k−1}, (p+1)/3^{k−1}]`,
간극은 `[(3p+1)/3^k, (3p+2)/3^k]`:

```
field(r,n):  n=0 → 0
  r ∈ 간극  → (e_k/w_k)·6u(1−u),  u=(r−a)/w_k
  r < a     → p ← 3p        , 다음 준위
  r ≥ b     → p ← 3p+2      , 다음 준위
```

최대 `n`회 반복, 셀은 정수 `(p, 3^{k−1})`로만 유지.

**퍼텐셜.** `V_n(r) = ∫₀^r V′_n`이므로 **왼쪽 누적 offset이 붙는다** — V3가
놓쳤던 부분(D4):

```
r ≤ 1/3       V_n(r) = ½V_{n−1}(3r)
1/3<r<2/3     V_n(r) = ½(n−1)E₀ + E₀·smoothstep(3r−1)
r ≥ 2/3       V_n(r) = ½(n−1)E₀ + E₀ + ½V_{n−1}(3r−2)
```

검산: `V_n(1) = ½(n−1)E₀ + E₀ + ½(n−1)E₀ = nE₀` ✓ 정리 A.
**측정: 모든 `n`에서 오차 정확히 0.**

## 4. 수치 조건수 — 측정으로 확립

준위 `k` 기하는 `3^{-k}` 척도인데 장 계수는 `2(3/2)^k`로 커지므로, 끝점의
상대 섭동 `ε`는 장에서 **약 `3^k`배 증폭**된다. 실측 (n=4…15):

| 비교 | 상수 `C` (오차 ≈ `C·3^n`) |
|---|---|
| symbolic vs explicit | `2×10⁻¹⁶` |
| 정리 S 항등식 | `4×10⁻¹⁵` (`T_i`의 추가 나눗셈) |
| general IFS vs symbolic | `6×10⁻¹⁶` |

**삼진 주소를 정수로 유지**하면(반복 부동소수 나눗셈 대신) 기호적 평가기가
명시적 구현보다 **나쁘지 않다**. 정확한 유리수 기준 대비 (3,000점):

| n | explicit | symbolic |
|---|---|---|
| 5 | 4.9e−14 | 5.0e−14 |
| 8 | 1.4e−12 | 1.3e−12 |
| 12 | 6.6e−11 | 6.8e−11 |
| 15 | 1.7e−10 | **1.2e−10** |

`n ≥ 12`에서는 **두 부동소수 경로 어느 쪽도 정확하지 않다.** 안전 주장은
`n = 5`에만 의존한다(§STOP D).

## 5. 척도 전이 (H3)

`E_scale = sup_r |u_{n+1}(T_i(r)) − α·u_n(r)| / max(|α·u_n(r)|, 1)`

| family | max `E_scale` | 새 파라미터 | zero-shot |
|---|---|---|---|
| **`cantor_recursive`** | **6.1e−09** | **0** | **YES** |
| **`recursive_non_cantor`** | **7.2e−10** | **0** | **YES** |
| `periodic_procedural` | 4.50 | 24,573 | no |
| `shuffled_seeded` | 3.87e+02 | 24,573 | no |
| `center_anchored_seeded` | 5.62e+02 | 24,573 | no |

**정확한 척도 전이는 재귀 family에만 존재한다.** 그러나 칸토어가 재귀
비칸토어보다 낫지 않다 — 오히려 `ρ=0.28` 쪽이 조건수가 좋다.

## 6. Lower bound (표현 모델 명시)

**black-box interval oracle에 한정.** layout이 `N` 개의 독립적으로 손상 가능한
구간으로만 주어지고 성질 `P`가 성분별로 검사되어야 하면, 어떤 검증자도
worst case `Ω(N)` 질의가 필요하다 (adversary가 검사되지 않은 성분 하나를
손상시킬 수 있으므로).

**procedural / 닫힌 형식 주소지정 가능 layout에는 적용되지 않는다.**
이 제한을 지우면 정리 문구를 삭제한다 (STOP G). 실제로 `periodic`이
닫힌 형식이므로 이 하한에서 벗어나며, 그것이 §RESULTS의 post-hoc 정정이다.
