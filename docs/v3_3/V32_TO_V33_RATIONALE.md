# V3.2 → V3.3: 왜 질문을 바꾸는가

## 1. 바꾸지 않는 것

V3.2가 확정한 것은 **그대로 둔다.**

> **H1: `R_C > R_M` — NOT SUPPORTED.**
> Model A `C_PRACTICALLY_EQUIVALENT`(두 채점기 모두), Model B
> `E_INCONCLUSIVE_SCORER_DEPENDENT`. 폭·에너지 정합 대조군에 대한
> **13개 비교 중 칸토어 승리 0개.** 반대로 외부 채점기에서는 진짜 상수
> (−0.0091), 단일 광폭 장벽(−0.0203), minimax(−0.0075)가 칸토어를 이겼다.

V3.3은 이 결론을 **재검정하지 않는다.** positive가 나올 조건을 찾아 격자·예산·
지표를 바꾸지 않는다. LLM 실험은 오직 *기호적 제어기 ≡ 명시적 제어기* 확인에만
쓰인다.

## 2. 바꾸는 것

V1–V3.2는 전부 **"칸토어가 더 안전한가"**를 물었고, 네 번 아니라고 답했다.
V3.3은 다른 질문을 한다.

> **동일한 safety를 내는 다척도 제어기들 중에서, 칸토어의 정확한 자기유사성이
> 표현 복잡도 · 척도 확장 · 검증 비용에서 측정 가능한 이득을 주는가?**

가능한 최선의 결과는 **robustness-neutral but structure-positive**:
`R_C ≈ R_M` 이면서 `C_C < C_M`.

## 3. 왜 이 질문이 정당한가

정리 S는 **참이고 칸토어 고유**다 (V3에서 대조군 잔차 0.82–0.96 vs 칸토어 10⁻¹³).
V3.2가 보인 것은 그 성질이 **강건성과 무관**하다는 것이다 (r = +0.147).

참이지만 강건성을 예측하지 않는 성질이 **다른 무언가는 예측할 수 있다** —
그것이 무엇인지 묻는 것은 hypothesis shopping이 아니라, 이미 증명된 성질의
용도를 찾는 것이다.

## 4. 이 질문이 자기기만이 되지 않게 하는 장치

| 위험 | 장치 |
|---|---|
| "절차적이라 압축된다"를 칸토어 이득으로 착각 | **seeded shuffled 대조군 필수** (STOP B) |
| "재귀라서 좋다"를 칸토어 이득으로 착각 | **recursive non-Cantor 대조군 필수** (STOP C) |
| 지표를 칸토어에 유리하게 설계 | PRIMARY 3개를 **사전 봉인**, ICR은 secondary |
| gzip 우연 | 5개 축 분리 보고, gzip 단독 결론 금지 (STOP A) |
| 안전도 손실을 저렴함으로 상쇄 | Pareto에서 **safety gate가 선행** (STOP F) |
| symbolic ≠ explicit인데 safety 상속 | 정확 유리수 기준 대비 검증 (STOP D) |

## 5. 실제로 일어난 일

장치들이 **작동했다.**

* seeded shuffled와 periodic이 칸토어보다 **기술 길이가 짧았다** → M1 이득 없음
* recursive non-Cantor가 칸토어와 **모든 지표에서 동률** → Cantor-specific 아님
* 봉인된 인증 계수에 **칸토어에 유리한 오류**가 있었고, post-hoc 정정 후
  periodic이 더 쌌다 → M2 이득 없음

**최종 판정 `E_NO_STRUCTURAL_ADVANTAGE`.** 남은 유일한 분리축(정확한 척도 전이)
조차 재귀 일반의 성질이다.
