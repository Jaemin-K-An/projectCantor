# 행동적 경계 `τ_beh`

## 왜 사영 중점으로 부족한가
`τ_mid`는 harmful/harmless **표현**의 중점이다. guard가 감싸야 하는 것은
모델 **행동**이 바뀌는 지점이다. 둘이 일치할 이유가 없고, 실제로 **3.90 σ**
어긋났다.

## 비순환적 dose 설계
`v`가 단위벡터이므로 `h + λv`의 사영은 정확히 `z+λ`다. 회귀는 **실현된
사영**에 대해 수행하므로 적합된 양이 예측변수로 들어가지 않는다.

## 식별성 게이트 (8개, 전부 통과해야 함)
양 class 존재 · 기울기 비퇴화 · 방향 타당 · 전이가 z 범위 안 ·
CI 유한 · 적합 비평탄 · **전이 관측**(구간별 거부율이 0.5를 걸침) ·
**CI 폭 ≤ 3σ**

뒤의 둘은 초기 적합을 본 뒤 **추가**했다. 둘 다 식별을 더 **어렵게** 만든다.

## 결과
`τ_beh = −2.6263`, CI95 [−3.2470, −1.9724], slope +0.6955.
격자 ±3σ로는 전이 미관측 → −10σ까지 확장 후 1회 재적합(공개).
