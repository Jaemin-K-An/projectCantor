## 1. 내가 만든 vacuous test (harness §5)

`test/v3_3_2/test_v332.py:115`
```python
assert tok not in src....lower() or True   # 항상 참
```
**`or True`는 어떤 입력에도 통과한다.** 제거하고 실제 기능 검사로 교체:
서명 검사 + 동일 입력 → 비트 동일 출력 + 공통 재척도 불변(성질) + 표본 크기 반응.

* **`U_PHASE`** prefill→generation **체계적 이동** (불확실성 아님)
