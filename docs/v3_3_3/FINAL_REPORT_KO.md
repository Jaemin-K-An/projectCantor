# 칸토어 중삼분 비율의 깊이-3 최적성과 LLM 안전 제어 — 최종 실증 종결 (V3.3.3)

## 1. 최종 연구 질문

> 중삼분 칸토어의 `ρ=1/3`이 대칭 이진 3단 재귀 제어에서 수학적으로 최심부
> guard 폭을 최대화한다는 사실이, 실제 LLM의 행동적 안전 경계 불확실성,
> 잔차공간 교란, phase-aware 생성 안전성에서도 예측력을 가지는가?

**답: 부분적으로.** 수학은 참이고 메커니즘 수준에서 정확히 검증되었으나,
생성 수준으로는 다리가 닿지 않았다.

## 2. 다섯 층을 분리해 보고한다

| 층 | 판정 |
|---|---|
| **M1 수학** | `M1_CANTOR_UNIQUE_DEPTH3_GUARD_MAXIMISER` |
| **M2 행동적 경계** | `M2_BEHAVIORAL_BOUNDARY_IDENTIFIED` |
| **M3 불확실성 다리** | **취약** (q50 하나에 의존) |
| **M4 적대적 교차** | `SB_QUANTITATIVE_CONSISTENCY` |
| **M5 생성 안전** | `F_INCONCLUSIVE` |

**한 층의 성공은 다른 층의 증명이 아니다.** M1의 성립이 M5를 함의하지 않는다.

## 3. 수학 (M1) — 유도

최심부 guard 폭
```
G_n(ρ) = ρ^{n−1}(1 − 2ρ)
G_n′(ρ) = (n−1)ρ^{n−2}(1−2ρ) + ρ^{n−1}(−2) = ρ^{n−2}[(n−1) − 2nρ]
```
`(0, 1/2)`에서 유일한 정류점:
```
ρ_max(n) = (n−1)/(2n)
```

| n | 2 | **3** | 4 | 5 |
|---|---|---|---|---|
| `ρ_max` | 1/4 | **1/3** | 3/8 | 2/5 |

**`n = 3`에서만 `ρ_max = 1/3`이고, `G_3(1/3) = 1/27`.**

> 이것은 **깊이 3의 이 절대 guard 목적함수에 한정된** 칸토어 고유 positive다.
> `n ≠ 3`에서는 `ρ_max ≠ 1/3`이다. 일반화하지 않는다.

**1/3을 선택하는 독립적인 이유는 둘이며 혼동하지 않는다:**
**A.** 균형 목적 `κ=1` → `ρ*(κ)=1/(2+κ)=1/3` (V3.3.1)
**B.** 깊이 3 절대 guard 최대화 → `ρ_max(3)=1/3` (V3.3.3)

## 4. 행동적 경계 (M2)

V3.2·V3.3.2는 **사영 중점** `τ_mid`를 경계로 취급했다. 이는 표현의 성질이지
행동의 성질이 아니다. V3.3.3은 실제 생성 행동으로 `τ_beh`를 추정했다.

동결 격자 ±3σ가 전이를 포착하지 못하자 **외삽을 받아들이는 대신 게이트를
강화**하고(전이 관측 요구 + CI 폭 ≤ 3σ), 같은 교정 블록에서 격자를 확장해
한 번만 재적합했다. 전이 관측 후:

```
τ_beh = −2.6263,  CI95 [−3.2470, −1.9724],  slope +0.6955
τ_mid = +0.9887
간격  = 3.90 σ
```

> **사영 중점은 행동 경계에서 약 4σ 떨어져 있다.** 이전 버전들이 "경계
> 불확실성"이라 부른 양은 행동 경계에 대한 것이 아니었다.

## 6. 적대적 교차 (M4) — 정량적 일치

무작위 ±δ는 최악의 경우 정리를 검증할 수 없다. 정확한 최소 교차 거리로 교체:

* 위반 **0 / 39**
* 조밀 피복에서 `d_cross/G_n ∈ [1.000005, 1.009452]`
* 사전선언 허용오차 1 % → **QUANTITATIVE_CONSISTENCY**

**guard 기하는 실제 잔차 좌표에서 정확히 성립한다.**

## 7. 생성 안전 (M5) — 판정 불가

런타임 위상 검증 통과(prefill 1 / decode 47). 예산 6/7 정합
(`ρ=0.46`은 −11.1 %로 제외).

D_final 70 goal, robust safety AUC:
`1/3` vs `0.44`: `d=+0.00257`, CI95 **[−0.0158, +0.0213]**.
max-T 동시 신뢰대에서 **유의한 비교 0건**. benign utility는 **모든 ρ에서 동일**.

CI가 0을 배제하지도 SESOI ±0.02에 들어가지도 않으므로 **F_INCONCLUSIVE**.
"우월"도 "동등"도 주장할 수 없다.

## 8. 최종 결론

> **중삼분 비율 `ρ=1/3`은 깊이 3의 최심부 guard 폭을 최대화하는 유일한
> 축약비이며(`ρ_max(n)=(n−1)/(2n)`), 이 guard 기하는 실제 LLM 잔차 좌표에서
> 최소 교차 거리 기준으로 1 % 이내로 정확히 성립한다.**
>
> **그러나 이 수학적 최적성은 실제 생성 안전으로 이어지지 않았다.**
> 행동적 경계는 사영 중점에서 3.9 σ 떨어져 있고, 그로부터 유도한 불확실성은
> 깊이 3에서 어떤 ρ도 허용하지 않으며, 동일 예산 하 생성 실험에서
> `ρ=1/3`과 다른 비율의 차이는 검출 한계 아래였다.

**즉 M1과 M4는 성립하고 M5는 판정 불가다.** 이는 모순이 아니라
**수학적 guard 목적함수가 생성 수준 안전을 예측하지 못했다**는 하나의 결과다.

## 9. 한계

1. Model A 단독 · 단일 층 · 깊이 3 주력 · `C_rms=0.02` 선형 영역.
2. `D_final`은 **XSTest unsafe**로 JBB와 다른 모집단이며, JBB harmful 100개는
   전부 소진되었다. 외적 타당성은 이 모집단에 한정된다.
3. `τ_beh`는 **50개 프롬프트**에서 추정했고 CI 폭 1.38 σ다.
4. dose 격자를 한 번 확장했다(공개). 확장 없이는 전이가 관측되지 않았다.
5. AUC 확산 0.0254가 SESOI 0.02보다 커서 동등성도 주장할 수 없다 —
   **검정력 부족**이지 등가의 증거가 아니다.
6. 봉인 후 분류기를 1회 수정했다(출력 형식만, 판정 로직 불변, 기록됨).

## 10. 이 연구가 실제로 남기는 것

칸토어에 대한 답은 **"수학적으로 특별하지만 이 LLM의 생성 안전을 예측하지
못한다"**이다. 그러나 이전 가능한 교훈은 방법론이다:

* **안전 경계는 표현이 아니라 행동으로 정의해야 한다.** 사영 중점과 행동
  경계는 4 σ 어긋났고, 이전 세 버전이 그 차이를 몰랐다.
* **최악의 경우 정리는 최악의 경우 실험으로만 검증된다.** 무작위 교란은
  guard 정리를 시험할 수 없다.
* **불확실성 하나의 분위로 설계 결론을 내려서는 안 된다.**
* **위상별 교정은 코드에서 실제로 위상을 구분해야 한다.**
