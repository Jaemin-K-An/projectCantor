# 적대적 교차 — 무작위 교란의 대체

## 왜 무작위로는 안 되는가
guard 정리는 **최악의 경우** 진술이다. 무작위 ±δ는 보장을 깨는 방향을
시도하지 않을 수 있으므로 **평균적 강건성**만 측정한다.

## 정확한 최소 교차 거리
재귀 셀 분해를 따라 내려가 `r`이 속한 leaf의 양쪽 경계까지의 거리를 구하고,
guard 전체를 건너 **다른 leaf**에 도달하는 최소 `|t|`를 계산한다.
guard 안의 점은 0으로 두고 최악의 경우 통계에서 제외한다.

## 정리는 부등식이다
`d_cross ≥ G_n(ρ)`. `|비 − 1|`로 채점하는 것은 **잘못된 검정**이다 —
비가 1보다 큰 것은 실제 좌표가 최악의 위치를 채우지 않았다는 뜻이지
경계의 실패가 아니다. 올바른 검정은 (i) 위반 여부, (ii) 조밀 피복에서의 밀착도.
