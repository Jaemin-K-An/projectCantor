# V3.3.1 수학 — Guard–Resolution 최적성

## 0. 설정

이진 대칭 재귀 분할: 부모 셀을 `[child ρ | guard g | child ρ]`로 나눈다.

```
2ρ + g = 1        ⟹     g(ρ) = 1 − 2ρ,     0 < ρ < 1/2
```

* **ρ = refinement capacity** — 다음 척도에서 더 세밀히 제어할 수 있도록 유지되는 상태공간
* **g = guard capacity** — 경계 모호성·교정 오차·abstention을 흡수하는 영역

`dg/dρ = −2`이므로 **두 자원은 직접 경쟁한다.**

> **`g ≥ ρ`를 처음부터 가정하지 않는다.** 그것은 이미 칸토어를 가정하는 것이다.
> guard 요구는 자유 모수 **`g ≥ κρ`, `κ > 0`** 로 둔다.

---

## 정리 G — Guard-Constrained Optimal Ratio

**주장.** `g ≥ κρ` 하에서 실현가능한 최대 축약비는 유일하게
```
ρ*(κ) = 1/(2+κ)
```

**증명.** `1 − 2ρ ≥ κρ ⟺ 1 ≥ (2+κ)ρ ⟺ ρ ≤ 1/(2+κ)`. 상계에서 등호. ∎

**따름정리.** `κ = 1` ⟹ `ρ* = 1/3` — **중삼분 칸토어.**

---

## 정리 BGR — Balanced Guard–Resolution Minimax

**주장.** `B_κ(ρ) = min(ρ, g/κ)`는 `ρ = 1/(2+κ)`에서 **유일 최대**, 최댓값 `1/(2+κ)`.

**증명.** `(0,1/2)`에서 `d/dρ[ρ] = 1 > 0`이고 `d/dρ[g/κ] = −2/κ < 0`.
증가함수와 감소함수의 min은 교차점에서 유일 최대이며, 교차는
`κρ = 1 − 2ρ ⟺ ρ = 1/(2+κ)`. ∎

`κ=1`: `max min(ρ, 1−2ρ) = 1/3` at `ρ = 1/3`.

**시스템 성능은 refinement와 guard 중 더 부족한 쪽에 의해 제한된다** —
이것이 칸토어에 대한 가장 직접적인 positive 결과다.

---

## 정리 P — Constrained Pareto Optimality

실현가능 집합 `(0, 1/(2+κ)]`에서:

| 목적 | 도함수 | 단조성 |
|---|---|---|
| `R_ret = 2ρ` | `2` | **증가** |
| `d_H = ln2/ln(1/ρ)` | `ln2/(ρ ln²ρ)` | **증가** |
| `A_f = 1/(2ρ)` | `−1/(2ρ²)` | **감소** |
| `A_s = 1/(2ρ²)` | `−1/ρ³` | **감소** |

**네 목적이 모두 실현가능 상계에서 동시에 최적**이므로 유일 결합 최적점은
`ρ*(κ) = 1/(2+κ)`. `κ=1`에서 칸토어는 retention·차원을 최대화하고
장·민감도 증폭을 최소화한다. ∎

---

## 정리 R — Refinement Consistency

고정 준위 에너지 규약에서 `u_n = Σ_{k≤n} u_k`, `supp(u_k) = G_k`이고
`G_j`들이 서로소이므로
```
supp(u_{n+1} − u_n) = G_{n+1} ⊆ K_n
⟹  u_{n+1}(r) = u_n(r)   ∀ r ∈ S_n = ∪_{k≤n} G_k
```
**세밀화는 이전에 해결되지 않은 영역에만 개입을 추가한다.**
실측: 모든 `ρ ∈ {0.2, 0.25, 1/3, 0.4}`, `n ∈ {2,4,6}`에서
drift **정확히 `0.000e+00`**.

**따름정리 R.1 (일반 ρ):**
`μ(K_n) = (2ρ)ⁿ`, `μ(S_n) = 1 − (2ρ)ⁿ`, `μ(G_{n+1}) = g(2ρ)ⁿ`.
칸토어: `(2/3)ⁿ`, `1−(2/3)ⁿ`, `(1/3)(2/3)ⁿ`.

> **주의.** 정리 R은 **구조적 규약**(동일 `E₀`, 이득 재정규화 없음)에서만
> 성립한다. **배포 규약**에서는 `η_n ≠ η_{n+1}`이므로 옛 지지집합이
> 재척도되어 정확한 일치가 깨진다. 둘을 혼동하지 않는다.

## κ와 불확실성의 연결 (harness §42 **정정**)

불확실성 반경이 달성하려는 해상도에 비례한다고 두자: `δ = β·(leaf 폭) = β·ρⁿ`.

최심부에서 이웃 child로 직접 건너뛰려면 **level-n guard 전체**(폭 `ρ^{n−1}g`)를
통과해야 한다:
```
ρ^{n−1}(1−2ρ) ≥ β·ρⁿ   ⟹   1−2ρ ≥ βρ   ⟹   ρ ≤ 1/(2+β)
```
`ρ^{n−1}`이 **소거**되어 기준이 깊이 무관이 된다.

> **`κ = β`이고, 칸토어는 `β = 1`에 대응한다** —
> **불확실성 반경 = leaf 폭 하나**, 곧 달성하려는 해상도 그 자체.

harness §42는 양측 여유를 가정해 `κ = 2β`(칸토어 ⟺ β=1/2)라 했으나,
단일 섭동 `r → r+Δ`는 guard **전체**를 건너야 하므로 단측이 옳다.
합성 실험(worst-case 섭동, 200,000 상태)이 판정:
`κ=β` 중앙값 오차 **0.0011** (격자 0.02) vs `κ=2β` 0.0723 → **2β 기각**.

## 가정 민감도 — 이 정리는 보편적이지 않다

전체 반례는 [`COUNTEREXAMPLES.md`](COUNTEREXAMPLES.md). 요약:

1. **guard 제약이 없으면** `ρ→1/2`가 네 목적 전부에서 칸토어를 이긴다
2. **`κ ≠ 1`이면** `ρ* ≠ 1/3`
3. **새 coverage 증가분** `F_n = (1−2ρ)(2ρ)ⁿ`의 최적은 `n/(2(n+1))` — `n=2`에서만 1/3
4. **척도 불변성**을 버리면 예측이 완전히 무너진다

> **정확한 진술:** 칸토어는 *보편적으로* 최적이 아니라,
> **이진 대칭 재귀족 안에서 guard와 refinement를 동등 가중(κ=1)할 때
> 유일한 최적점**이다.
