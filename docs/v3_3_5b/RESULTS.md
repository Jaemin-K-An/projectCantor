# V3.3.5b 결과 — Stage A

## 1. 정합 예산의 구성

`Δh_t = s·q_t·‖h_t‖₂·v_ref` (‖v‖=1) ⟹ `‖Δh_t‖/‖h_t‖ = q_t` 정확.
**`B₂ = √(Σ q_t²)`**. 단일 상태 `q₁ = B₂`; 균일 T 상태 `q_t = B₂/√T` ⟹
`√(T·B₂²/T) = B₂`. **모든 schedule이 정확히 같은 궤적 L2 에너지를 쓴다.**

실측: DEV·CONFIRM 합계 **0/2800 행이 ±3 % 밖** — 정합 완전.
`‖w‖₂ = 1` 모든 schedule에서 확인.

## 2. 사전 선언 예산 격자는 **효과 문턱 아래**였다

`q ≤ 0.05` 격자에서 **35개 셀 전부 거부율 0.625로 동일** — 어떤 arm도 움직이지
않았다. 두 팔이 모두 정지해 있으면 비교가 성립하지 않는다.

측정된 regime gap (`‖h_P0‖ = 18.449`):

| | q |
|---|---|
| 사전 선언 cap | 0.05 |
| **효과가 시작되는 q** | **0.10** (cap의 2×) |
| V3.3.3 global dose (−3σ) | 0.151 (3.0×) |
| V3.3.3 global dose (−10σ) | **0.502 (10.0×)** |

coherence는 `q = 1.6`에서도 **0.998**이다. cap의 근거(붕괴 방지)가 여기서는
구속하지 않으므로, **cap을 coherence 게이트(≥0.8)로 대체**하고 격자를
효과 영역까지 확장했다 — 프로토콜에 명시 공개.

## 4. V3.3.5a의 P0 결론도 정정된다

정상 범위(q = 0.1–0.8)에서 P0는 **깨끗하고 단조**하다
(0.683 → 0.617 → 0.433 → 0.133). V3.3.5a가 P0를 "인과적이지 않다"고 판정한 것은
**q ≈ 5.4의 비정상 dose** 때문이었다. **P0는 이 모델에서 가장 강한 단일 지렛대다.**
