# V3.3.5a 감사 — 누적 교란

## 철회하는 주장

V3.3.5a는 다음을 사실로 보고했다:

> `PHASE_LEVERAGE_IS_DISTRIBUTED` — 거부 제어는 시간적으로 분산되어 있다.

**이 주장을 철회한다.** 근거였던 비교가 **예산 미정합**이었다.

## 교란의 정량화

`fit_behavioral_boundary.py`의 dose hook은 `λ·v`를 **모든 forward**에 더했고,
prefill에서는 **모든 시퀀스 위치**에 broadcast했다. `max_new_tokens=48`이므로
**48개 forward**를 건드렸다. P0-only·G1-only는 **1개 상태**다.

| | 비 |
|---|---|
| 상태별 q가 같다면 L2 예산 비 | **√48 = 6.9×** |
| L1 예산 비 | **48×** |
| **V3.3.5a가 관측한 레버리지 비** | **19–23×** |

관측값이 두 값 **사이에** 있다. 따라서 **누적만으로도 설명 가능**하며,
분산 가설의 증거가 되지 못한다.

## 열린 설명들

`H1` 진짜 시간적 분산 · `H2` 반복 개입 누적 · `H3` 프롬프트 모집단 차이 ·
`H4` 초대형 dose의 비선형 반응 · `H5` 조합.

V3.3.5a는 **H3도** 안고 있었다 — 세 위상이 서로 다른 프롬프트 집합에서 나왔다.

## 극단 dose 재해석

V3.3.5a의 P0 실험은 λ를 **원 사영 단위**로 −100까지 밀었다.
`‖h_P0‖ ≈ 18.45`이므로 이는 **q ≈ 5.4**, 즉 잔차 노름의 **5배**다.
그 영역의 비단조성과 붕괴(coherence 0.000)는 모델을 작동 영역 밖으로
밀어낸 결과이며, **국소 인과 민감도의 증거가 아니다.**

전부 `OUT_OF_LOCAL_OPERATING_REGIME`로 표시하고 보존한다.
