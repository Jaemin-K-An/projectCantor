# 정합 예산 시간 인과성 종결 (V3.3.5b, 최종)

## 1. 이 보고서는 칸토어에서 시작하지 않는다

경험적 문제에서 시작한다.

1. 단일 상태(P0/G1) 개입은 약했다 (V3.3.5, V3.3.5a).
2. 과거 all-forward 개입은 강했다 (V3.3.3).
3. **그러나 반복 개입 에너지가 정합되지 않았다.**
4. V3.3.5b는 그 교란을 제거하고 인과성을 다시 시험한다.
5. 분산이 살아남는 경우에만 궤적 모형으로 넘어간다.
6. 칸토어는 그 다음에야 등장한다.

## 3. 철회 — "시간적으로 분산되어 있다"

V3.3.5a의 GLOBAL 비교는 **48개 forward** 대 **1개 상태**였다.
상태별 q가 같다면 L2 비는 √48 = 6.9×, L1 비는 48×이고,
관측된 19–23×는 **그 사이에 있다.** 누적만으로 설명 가능하므로
`PHASE_LEVERAGE_IS_DISTRIBUTED`를 **철회**한다.

## 4. 정합 실험

`B₂ = √(Σq_t²)`를 모든 schedule에 **정확히 동일**하게 맞추고
(0/2800 행이 ±3 % 밖), 같은 프롬프트·방향·층·디코딩으로,
프롬프트 내 짝지어 비교했다.

**결과: 같은 에너지에서 P0에 집중하는 것이 분산보다 유의하게 낫다.**
`B₂=0.8`에서 EARLY_8 − P0_ONLY = **−0.367 [−0.569, −0.164]**.

## 5. 두 가지 정정

**(a) 사전 격자가 효과 문턱 아래였다.** `q ≤ 0.05`에서 35개 셀 전부 무반응.
효과는 `q ≈ 0.10`에서 시작하고 과거 global dose는 `q ≈ 0.50`이었다.
coherence가 `q=1.6`에서도 0.998이므로 cap을 coherence 게이트로 대체했다(공개).

**(b) V3.3.5a의 P0 실패는 dose 오류였다.** λ = −100은 `q ≈ 5.4`, 즉 잔차 노름의
5배다. 정상 범위에서 P0는 단조롭고 가장 강하다.

## 6. 최종 결론

> **과거 all-forward 개입의 큰 행동 효과는 시간적으로 분산된 거부 메커니즘의
> 증거가 아니라, 주로 반복된 개입 에너지에 기인한다. 총 궤적 L2 에너지를
> 정확히 맞추면 개입을 P0 한 상태에 집중하는 편이 여러 상태에 나누는 것보다
> 같거나 유의하게 낫다.**

따라서 궤적 좌표를 만들 근거가 없고, 칸토어를 시간축으로 확장할 근거도 없다.
`D_final_traj`는 쓰지 않았다.

## 7. 한계

1. Model A 단독·층 14·단일 방향·refusal proxy(의미 평가기 미검증).
2. `q > 0.05`는 사전 선언 cap을 넘는다. coherence는 유지되나 배포 가능한
   개입 크기는 아니다 — **인과 탐침**이지 컨트롤러 설정이 아니다.
3. `B₂` 정합은 L2 기준이다. `B₁`은 정합되지 않으며 분산 schedule이 더 크다.
   L1이 옳은 비용 척도라면 결론이 달라질 수 있다.
4. K=8 지평. 더 긴 지평에서 분산의 이점이 나타날 가능성은 배제하지 못한다.
5. 효과는 거부율 감소 방향(불안전 방향)으로 측정했다. 안전 방향의 대칭성은
   시험하지 않았다.

## 8. V1 → V3.3.5b

```
V1        칸토어 도함수 게이트 → 겉보기 이득 → confound
V2–V3.2   정합 대조군에서 raw safety 우월성 없음
V3.3–.2   왜 1/3인가 — guard/refinement 수학
V3.3.3    표현 중점과 행동 경계가 3.90 σ 불일치
V3.3.4    r-공간 maximin, 로지스틱 왜곡이 exact 최적을 0.296으로 이동
V3.3.5    좌표 보존 → affine 강제 → exact 최적 1/3, 인증서 위반 0건
          그러나 G1 단일 상태 경계 식별 불가
V3.3.5a   P0로 이동 → 토큰 1에 도달 확인, 그러나 여전히 약함
          (단, dose가 q≈5.4로 과대했음이 이번에 밝혀짐)
V3.3.5b   예산 정합 → 분산 가설 기각, 누적이 설명
          → P0 집중이 최선, 시간축 확장 근거 없음
```

**칸토어에 대한 최종 답은 바뀌지 않는다.** `ε(ρ)=2W ρ²(1−2ρ)`는 참이고
`ρ=1/3`이 유일 최적이다. 부족한 것은 여전히 **그 인증서를 정박시킬 행동적
좌표**이며, 이번 버전은 그것을 시간축으로 확장해도 얻을 수 없음을 보였다.

프로젝트는 여기서 끝낸다.
