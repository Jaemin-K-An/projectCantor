# 칸토어 중삼분 구조와 LLM 잔차 안전 제어 — 최종 브리지 보고 (V3.3.2)

## 1. 한 문단 요약

V3.3.1은 **수학적 positive**(균형 guard–resolution minimax에서 ρ=1/3이 유일
최적)와 **실증 브리지**를 함께 주장했다. V3.3.2는 그 브리지를 감사해
**다섯 개 결함을 모두 확인**했고, 브리지를 처음부터 다시 만들었다.

수정된 측정에서: 진짜 두-class 위상 calibration, ρ와 무관한 추정량 불확실성
`δ_abs = 0.0253`, 미접촉 `D_final` 위의 실제 좌표 실험.

> **결과: 수학은 그대로 참이고, 실제 LLM은 1/3을 선택하지 않는다.**
> 측정된 불확실성이 함의하는 비율은 **ρ ≈ 0.46**이며, 실제 좌표 Pareto에서
> 칸토어는 `ρ=0.40`에 **엄격히 지배**된다.

## 3. V3.3.1 수학적 positive — 유지

`ρ*(κ) = 1/(2+κ)`, `κ=1 ⟹ ρ*=1/3`. 정리 G/BGR/P/R + 반례 전부 유지.

## 4–5. 실증 브리지 감사 — 왜 무효였는가

1. **generation calibration이 calibration이 아니었다** — 공격된 harmful
   **한 class의 평균**을 τ라 불렀다. harmless를 보지 않은 추정량은 경계를
   찾을 수 없다.
2. **hook에 위상 인식이 없었다** — 단일 τ/σ를 모든 forward에 적용했다.
   "phase-specific"은 어느 단일 값을 쓸지만 바꾼 것이다.
3. **`eps_cal`은 추정량 불확실성이 아니었다** — 같은 사영에 두 좌표변환을
   적용한 **표본 변동성 0의 결정론적 offset**이다.

⟹ `q50 = 0.111`, `n_max = 1~2`, "메커니즘 설명" **전부 철회**.

## 6–8. 수정된 측정

**진짜 위상 calibration** (두 class, clean, PHASE G1에 prompt당 정확히 1관측):
P `τ=+2.101, σ=1.317` / G1 `τ=+0.989, σ=0.926`.

**세 양을 분리:**
* `U_EST` (**primary**) — prompt 군집 부트스트랩 20,000회, **ρ 무관**.
  `δ_abs` q50 = **0.0253**, q95 = 0.0722.
* `U_PHASE` (**편향**, 불확실성 아님) — `m_phase = −0.845σ`, `δ_phase_r = 0.144`,
  `σ_G/σ_P = 0.703`. V3.2 컨트롤러가 구조적으로 저지른 오차.
* `U_STATE` — secondary only.

## 9–13. 절대 guard 기하 (신규 수학)

`G_n(ρ) = ρ^{n−1}(1−2ρ)`, `G_n′ = ρ^{n−2}[(n−1)−2nρ]` ⟹
**`ρ_guard_max = (n−1)/(2n)`**.

* **AG.1** `n=3` ⟹ `ρ_guard_max = 1/3` **정확히** (칸토어가 최심부 guard 폭을
  유일 최대화, `G_3,max = 1/27`)
* **AU.1** `n=2, δ=1/9` ⟹ 근 `{1/6, 1/3}`, **오른쪽 근 = 1/3** (오차 2.3e−15)
* **반례** `n>3`에서 `ρ_guard_max > 1/3` (n=5 → 0.4). **칸토어는 최대화하지 않는다.**

## 14–18. 실증 결과

**`δ_abs`는 1/9가 아니다.** 측정 분포는 0.025–0.072이고 1/9=0.111은 **밖**이다.
V3.3.1의 일치는 **깨진 추정량의 인공물**이었다.

**예측 `ρ_abs*`:** n=2 → 0.473, n=3 → 0.432, n=5 → 실현 불가.
95 % CI가 **모든 깊이에서 사전등록 밴드 [0.303, 0.363] 밖**.

**System B (실제 D_final 좌표):** 이론이 실측 경계를 **맞힌다** —
n=2 실측 (0.44, 0.50] vs 이론 0.473, n=3 실측 (0.40, 0.44] vs 이론 0.432.
그러나 Pareto에서 **칸토어는 front에 없다**: n=3에서 `ρ=0.40`이 같은
zero regression에 abstention 0.602 (칸토어 0.915).

## 26. 한계

1. `δ_abs`는 **10개 calibration prompt**의 군집 부트스트랩이다. τ 95 % CI
   [0.583, 1.352]는 넓고, `ρ_pred` CI도 넓다. **표본이 작다.**
2. `D_final`은 **XSTest unsafe**이며 JBB와 **다른 모집단**이다.
   결과는 그 모집단에 일반화된다.
3. Model A 단독, 단일 층, `n ∈ {2,3,5}`.
4. System A(부드러운 장벽 → 실제 생성 안전)의 완전한 ρ 격자 실행은
   compute 제약으로 미실행. System B 결과를 System A로 자동 확장하지 않는다.
5. **System B 실행이 봉인보다 앞섰다** (§RESULTS §6 공개).
6. `M_PLAUSIBLE`은 interaction 실험 부재를 뜻한다. 과거 null의 **원인**은
   확정되지 않았다.

## 27. V1 → V3.3.2 통합

```
V1–V3.2   칸토어의 raw safety 우월성 없음
V3.3      구조적 우월성 없음
V3.3.1    수학: 균형 κ=1에서 ρ=1/3 유일 최적  ← 유지
V3.3.2    브리지 재구축: 측정된 불확실성은 ρ≈0.46을 선택
          → 이 LLM은 균형 체제에 있지 않다
```

## 28–30. 최종 결론

> **칸토어 중삼분 비율 1/3은 균형 guard–resolution minimax 문제의 유일해이며,
> 깊이 3에서는 최심부 guard 폭을 유일하게 최대화한다.** 이 수학은 참이고
> 반례까지 포함해 검증되었다.
>
> **그러나 이 LLM에서 독립적으로 측정한 경계 불확실성은 1/3을 선택하지
> 않는다.** `δ_abs ≈ 0.025`는 훨씬 큰 refinement 비율을 허용하고, 실제 잔차
> 좌표 위 Pareto에서 칸토어는 `ρ ≈ 0.40`에 지배된다.
>
> 즉 **칸토어의 최적성은 특정 설계 체제(κ=1)의 성질이고, 측정된 LLM은 그
> 체제에 있지 않았다.** 수학 positive와 실증 negative는 모순이 아니라
> **가정이 성립하지 않았다는 하나의 결론**이다.

가장 이전 가능한 성과는 칸토어에 관한 것이 아니라 **방법에 관한 것**이다:
안전 경계 불확실성은 **두 class·위상별로** 추정해야 하고, 그것을 컨트롤러
파라미터와 **독립적으로** 측정해야만 어떤 기하가 적절한지 물을 수 있다.
V3.3.1은 그 두 조건을 모두 어겼고, 그래서 우연한 일치를 발견으로 착각했다.
