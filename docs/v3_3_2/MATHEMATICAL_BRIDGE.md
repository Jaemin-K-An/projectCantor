# V3.3.2 절대 불확실성 guard 기하

## 0. 두 불확실성 모델 (절대 혼합 금지)

| | 모델 | 정의 | 용도 |
|---|---|---|---|
| **U1** | scale-invariant **설계** 모델 | `δ = β·ρⁿ` | 이론/합성 전용. `κ = β`, `ρ* = 1/(2+β)` |
| **U2** | **절대** LLM 불확실성 | `δ_abs`를 **ρ와 무관하게** 측정 | 실증 브리지의 primary |

`δ := βρⁿ`을 실증 정의로 쓰면 **불확실성이 컨트롤러의 함수**가 되어
답이 질문에 이미 들어간다. V3.3.2의 primary는 **U2**다.

## 정리 AG — finest guard의 최대점

깊이 `n`에서 최심부 guard 폭:
```
G_n(ρ) = ρ^{n−1}(1 − 2ρ)
G_n′(ρ) = ρ^{n−2}[(n−1) − 2nρ]
```
⟹ **`ρ_guard_max(n) = (n−1)/(2n)`**, `G_n,max = (1/n)[(n−1)/(2n)]^{n−1}`

| n | 2 | **3** | 4 | 5 | 6 |
|---|---|---|---|---|---|
| `ρ_guard_max` | 0.2500 | **1/3** | 0.3750 | 0.4000 | 0.4167 |
| `G_n,max` | 0.12500 | **1/27** | 0.01318 | 0.00512 | 0.00209 |
| `G_n(1/3)=3^{-n}` | 0.11111 | **1/27** | 0.01235 | 0.00412 | 0.00137 |

### 따름정리 AG.1 — `n = 3`
`ρ_guard_max(3) = 2/6 = 1/3` **정확히**. 중삼분이 깊이 3에서
**최심부 guard 폭을 유일하게 최대화**하며 `G_3,max = G_3(1/3) = 1/27`.

### 반례 — `n > 3`
`(n−1)/(2n) > 1/3 ⟺ 3(n−1) > 2n ⟺ n > 3`.
`n=5`에서 0.4. **칸토어는 `n>3`에서 `G_n`을 최대화하지 않는다.**

## 정리 AU — 절대 불확실성 실현가능성

고정 `δ > 0`에 대해 `{ρ : G_n(ρ) ≥ δ}`는
`δ > G_n,max`이면 **공집합**, 아니면 `G_n(ρ) = δ`의 두 근 사이 구간이다.
retention `2ρ`가 증가하므로 **retention 최대 해는 오른쪽 근**:
```
ρ_abs*(n, δ) = max{ ρ ∈ (0,1/2) : G_n(ρ) ≥ δ }
```

### 따름정리 AU.1 — `n = 2`, `δ = 1/9`
`ρ(1−2ρ) = 1/9 ⟺ 18ρ² − 9ρ + 1 = 0 ⟺ ρ ∈ {1/6, 1/3}`.
오른쪽 근 = **정확히 1/3** (수치 검증 오차 2.3e−15).

> AU.1이 말하는 것: **만약** 측정된 불확실성이 1/9 근처라면, 깊이 2의
> retention-최대 해가 중삼분이다 — `κ=1` 가정 없이 **불확실성으로부터 유도**.
> **말하지 않는 것:** 측정된 불확실성이 실제로 1/9 근처인지.
> 그것은 §RESULTS의 실증 문제이고, 답은 **아니오**였다.
