**정리 AU가 실제 LLM 좌표 위에서 예측력을 보인다.**

### 그러나 칸토어를 선택하지 않는다 (depth 3)

| ρ | regression | abstention | Pareto front |
|---|---|---|---|
| 0.20–0.28 | 0.000 | **1.000** | 아니오 (퇴화) |
| **1/3** | 0.000 | 0.915 | **아니오** |
| 0.36 | 0.000 | 0.813 | 아니오 |
| **0.40** | **0.000** | **0.602** | **예** |
| 0.44 | 0.016 | 0.393 | 예 |

`ρ = 0.40`이 **같은 zero regression에 abstention 0.602 vs 칸토어 0.915** —
**칸토어는 엄격히 지배된다.** depth 2에서도 front는 `{0.44}`뿐이다.

> **abstention 1.000의 zero regression은 퇴화**다 — 컨트롤러가 항상 보수적
> 행동만 하면 regression은 자명하게 0이다. 그래서 regression 단독이 아니라
> (regression, abstention) 쌍으로 판정한다.

depth 5에서는 `ρ=0.40`(d=−0.0417)과 `0.44`(d=−0.2932)가 칸토어보다 regression이
**유의하게 많다**. 그러나 칸토어의 abstention이 0.966이라 이 역시 퇴화 영역이다.

## 5. 판정

```
MATH      : A_MATH_CANTOR_BALANCED_OPTIMUM
EMPIRICAL : C_ABSOLUTE_UNCERTAINTY_SELECTS_OTHER_RHO
MECHANISM : M_PLAUSIBLE
```

* **수학은 확정.** `ρ*(κ)=1/(2+κ)`, κ=1 ⟹ 1/3 유일. AG.1(n=3에서 1/3이 guard
  폭 최대), AU.1(n=2, δ=1/9 ⟹ 1/3) 모두 증명·검증.
* **실증은 다른 ρ를 선택.** 독립 측정된 `δ_abs`가 함의하는 것은 ρ ≈ 0.46이며,
  사전등록 칸토어 밴드 밖이다. **이 모델은 균형 κ=1 체제에 있지 않다.**
* **메커니즘은 M_PLAUSIBLE.** `G_5,max = 0.00512 < δ_abs = 0.0253`이므로
  V3.1/V3.2가 의존한 미세 guard가 측정된 불확실성보다 좁은 것은 사실이나,
  그것이 과거 null의 **원인**임을 보인 interaction 실험은 없다.
  **V3.3.1의 "메커니즘 설명" 주장은 자동 상속하지 않는다.**

## 6. 절차 공개

**System B의 `D_final` 실행이 봉인보다 먼저 이루어졌다.** 입력(`δ_abs`,
guard 분류기, ρ 격자)은 모두 사전 확정되어 있었고 결과를 본 뒤 어떤 규칙도
바꾸지 않았으나, 순서 규율은 지키지 못했다. 따라서 System B 결과는
**confirmatory-with-disclosure**로 보고하며 봉인 파일에 명시했다.
