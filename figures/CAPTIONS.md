# Figure captions

All figures regenerated by `scripts/generate_all_figures.jl`.


### FIG 1 — `fig01_cantor_staircase.png`

C_n(x) for n = 1…8 on [0,1] (dimensionless state x, dimensionless value). The shaded band is the safe set S = [1/3, 2/3], which is the level-1 removed middle third and therefore a plateau of C_n for EVERY n ≥ 1.


### FIG 2 — `fig02_derivative_support.png`

Top: C'_n for n = 1,2,3 — height (3/2)^n on a set of measure (2/3)^n, zero elsewhere; the product is 1 for every n. Bottom: the pass set K_n as a function of n; green lines mark ∂S. Note the safe set is white (blocked) at every n, which is the content of Theorem 1.


### FIG 3 — `fig03_numerical_integration.png`

(a) midpoint-rule estimate vs n for seven grid spacings, against the two Δx-independent rules. (b) error vs Δx, log–log. (c) log₁₀ error heat map with the ρ = 1 contour. (d) all 84 (n, Δx) cases collapse onto the single dimensionless number ρ = Δx·3ⁿ: the error is negligible for ρ ≲ 0.1 and O(1) for ρ ≳ 10. Analytic truth is 1 exactly at every n; every deviation shown is a property of the quadrature rule.


### FIG 4 — `fig04_baseline_reproduction.png`

Reproduction of the original study (α=0.8, A=1.5, ω=4, h₀=0.15, T=30, RK4 Δt=10⁻³). Reproduced occupancies 29.80 / 98.17 / 97.43 % vs the original 29.8 / 98.2 / 97.4 %. The orange trace is the gate value: for C₃ and C₅ it is ZERO at t=0 because h₀=0.15 ∈ (1/9, 2/9) is already a flat interval, and it is open for only 0.17 % / 0.13 % of the horizon.


### FIG 5 — `fig05_h0_n_occupancy.png`

Safe-set occupancy R_safe on the (h₀, n) plane at the original operating point. n = 0 is the ungated system. The two stars are the ONLY two cells the original study measured. Occupancy is far from uniform in h₀, and rows n ≥ 2 are not systematically brighter than n = 1.


### FIG 6 — `fig06_h0_n_hitting_time.png`

First hitting time τ_S = inf{t : h(t) ∈ S}. White/NaN cells never reached S within T = 30. Bright bands away from S are trapping regions: flat intervals far from the safe set where the gate blocks the very disturbance that would have carried the state into S.


### FIG 7 — `fig07_A_omega_phase.png`

Mean R_safe over all 99 initial conditions, on the (A, ω) plane at α = 0.8. The ungated system degrades sharply for large A and small ω (the disturbance outruns the restoring force); every gated system is nearly flat, and the gated panels are almost indistinguishable from one another.


### FIG 7b — `fig07b_alpha_A_phase.png`

As FIG 7 but on the (α, A) plane at ω = 4. The ungated system's occupancy tracks the analytic prediction (2/π)·asin(√(α²+ω²)/(6A)).


### FIG 5b — `fig05b_n_distribution.png`

R_safe distribution for each order n over all 196 020 sweep cells. Means, medians and IQRs are shown because the mean alone hides that every gated order has a long lower tail. The mean is NOT monotone in n: it peaks at n = 1 and has a minimum near n = 7.


### FIG 8 — `fig08_ablation_families.png`

All five families block exactly the same amount of state space, 1−(2/3)ⁿ. Pooled over 25 h₀ × 3 A × 3 ω at α = 0.8; G2 and G5 additionally averaged over 30 random layouts each. Ribbons are ±σ/4. Any separation between curves is an effect of ARRANGEMENT, not of measure.


### FIG 9 — `fig09_cantor_minus_control.png`

ΔR_safe = R(Cantor) − mean over 30 measure-matched control layouts, averaged over A and ω, on the (h₀, n) plane. Red = Cantor better, blue = control better. A structural advantage would show as a uniformly red map.


### FIG 10 — `fig10_seed_distribution.png`

Cantor is never compared to a single random draw. Histograms are the pooled R_safe of 30 random layouts × 25 initial conditions; the red line is the Cantor mean over the same initial conditions.


### FIG 11 — `fig11_hard_vs_smooth.png`

(a) occupancy vs β. (b) the gate profile near ∂S. (c) g_β(1/3) → 1/2 as β → ∞ because 1/3 is an ENDPOINT of a pass interval, so the Theorem-2 guarantee A·g(∂S) < α/6 can never be met for A ≥ α/3 no matter how sharp the gate. (d) every run to the right of the red line is guaranteed invariant; the guarantee is sufficient, not necessary.
